# forging Specification

## Purpose
定义装备锻造与强化系统对玩家可观察的行为契约：图纸学习与列表、自动与手动锻造、三性匹配与品质分、稀有度产出、强化三阶段与成功率、灵石与锻材消耗、失败降级、图纸门槛与里程碑奖励。公式、数据模型与配置细节见同目录 design.md。

## Requirements

### Requirement: 图纸学习与列表

系统 MUST 支持通过「使用 [图纸名]」学习锻造图纸。同一图纸 MUST NOT 重复学习，重复时拒绝并提示已学会；非图纸物品 MUST 拒绝。学习成功后 MUST 消耗 1 件图纸并回复所学图纸名称。系统 MUST 支持「锻造列表」展示已学图纸（编号、名称、品阶、产出装备），空列表 MUST 提示尚未学会任何图纸。

#### Scenario: 学习图纸

- **WHEN** 玩家背包中有「青锋刀图」并发送「使用 青锋刀图」
- **THEN** 学会该图纸，消耗 1 件，回复学习成功与图纸名称

#### Scenario: 查看列表

- **WHEN** 玩家已学会至少一张图纸并发送「锻造列表」
- **THEN** 回复编号列表，每项含图纸名称、品阶与产出装备名

### Requirement: 自动锻造

系统 MUST 支持「锻造 [图纸名]」自动锻造：按名称匹配已学图纸，从背包自动挑选最多 3 种锻材并计算数量，使累计三性落在图纸要求区间内；无锻材 MUST 提示锻材不足；任一属性不足或超限 MUST 报错且不消耗材料。成功后 MUST 按实际用量扣减锻材、生成装备并回复装备名、稀有度与品质分。仅持有图纸未学习时 MUST 提示先「使用」学习。

#### Scenario: 自动锻造成功

- **WHEN** 玩家已学目标图纸且背包锻材满足全部三性要求
- **THEN** 系统自动选材，扣减锻材并生成装备，回复稀有度与品质分

#### Scenario: 属性不足

- **WHEN** 背包锻材无法满足图纸某一属性下限
- **THEN** 回复缺少的锻材属性，不消耗任何材料

#### Scenario: 未学图纸引导

- **WHEN** 玩家发送「锻造 [名称]」但只持有同名图纸、尚未学习
- **THEN** 回复提示背包中有同名图纸，请先「使用 [图纸名]」学习

### Requirement: 手动锻造

系统 MUST 支持「锻造 [锻材名数量 ...]」手动锻造，输入格式为「名称紧连正整数数量」（如 `玄铁矿石3`），最多 3 段，超出 MUST 报最多 3 种；系统 MUST 用指定锻材的三性累计匹配任一已学图纸（取第一个满足者）；命中时 MUST 按指定数量扣减锻材并生成装备；无图纸匹配 MUST 报「锻材三性不匹配任何锻造图纸」且不消耗材料；数量不足时 MUST 报错并整体回滚。

#### Scenario: 手动锻造成功

- **WHEN** 玩家发送「锻造 玄铁矿石3 紫金砂1」且累计三性满足某已学图纸
- **THEN** 扣减指定锻材并生成装备，回复品质分与消耗明细

#### Scenario: 无匹配图纸

- **WHEN** 指定锻材的累计三性不落在任何已学图纸的区间内
- **THEN** 回复三性不匹配任何锻造图纸，不消耗材料

#### Scenario: 超过三种锻材

- **WHEN** 玩家一次指定 4 种及以上锻材
- **THEN** 拒绝并提示最多只能使用 3 种锻材

### Requirement: 品质分与稀有度产出

系统 MUST 按各属性相对要求区间中心的接近度计算达标度（中点为 1，单项低于 0 截断），取三项平均得品质分，并按图纸品阶加成（每品阶 +0.02）。系统 MUST 按最终分选择稀有度权重池加权随机产出稀有度，并在该稀有度区间内随机品质系数与词条数量（属性词条数值 1~4，传说可含固定值特殊词条）。产出装备名 MUST 包含稀有度后缀。

#### Scenario: 高品质产出

- **WHEN** 累计三性接近区间中心，最终分 ≥ 0.9
- **THEN** 从 LEGENDARY/EPIC 池中 roll 稀有度并生成对应装备

#### Scenario: 低品质产出

- **WHEN** 累计三性仅勉强满足下限，最终分 < 0.5
- **THEN** 从 COMMON/BROKEN 池中 roll 稀有度并生成对应装备

### Requirement: 强化上限与成功率阶段

装备强化 MUST 按稀有度设置上限（破旧 +3、普通 +5、稀有 +8、史诗 +12、传说 +18），达到上限 MUST 拒绝强化。强化 MUST 分三阶段：+0→+3 必定成功；+4→+9 按固定基础概率（80/75/70/65/60/55）乘稀有度修正（传说 ×0.9、史诗 ×0.95、稀有 ×1.0、普通 ×1.05、破旧 ×1.1）；+10→上限 以材料三性相对放大约束（图纸约束 ×(1+(目标等级-9)×0.3)）的品质分作为成功率，完美命中可达 100%。

#### Scenario: 安全期强化

- **WHEN** 玩家将 +2 装备强化到 +3
- **THEN** 必定成功，仅消耗灵石

#### Scenario: 概率期强化

- **WHEN** 玩家强化 +4 至 +5 的稀有装备
- **THEN** 按 75% × 1.0 的成功率 roll 结果，消耗灵石与锻材

#### Scenario: 图纸期强化

- **WHEN** 玩家强化 +10 以上装备且材料三性完美命中放大约束中心
- **THEN** 成功率为 100%

### Requirement: 强化消耗

每次强化 MUST 消耗灵石，公式为 `50 × 稀有度系数 × (1 + 目标等级 × 0.3)`（系数：破旧 0.5、普通 1、稀有 2、史诗 4、传说 8）；+4 及以上 MUST 额外消耗锻材。灵石不足 MUST 拒绝强化并提示所需与当前数量；灵石与锻材 MUST 在判定成功前扣除，失败不退还。

#### Scenario: 灵石不足

- **WHEN** 玩家灵石少于本次强化所需
- **THEN** 拒绝强化，回复所需灵石与当前余额，装备等级不变

#### Scenario: 锻材消耗

- **WHEN** 玩家强化 +4 及以上装备成功或失败
- **THEN** 本次选定的锻材均被扣除，不因失败退还

### Requirement: 强化失败惩罚

强化失败时装备 MUST NOT 损坏；强化等级 MUST 降低 1 级（最低 +0），并 MUST 回复新等级与实际成功率。

#### Scenario: 强化失败

- **WHEN** 玩家强化 +6 装备失败
- **THEN** 装备降为 +5，回复失败信息与成功率，不损坏装备

### Requirement: 图纸门槛

+0→+9 强化 MUST NOT 要求持有图纸；+10 及以上 MUST 要求玩家已学该装备对应的锻造图纸，未持有时 MUST 拒绝并提示需要图纸。掉落装备（无对应图纸）MUST 只能强化到 +9。

#### Scenario: 无图纸强化 +10

- **WHEN** 玩家尝试将掉落装备从 +9 强化到 +10 且未学过对应图纸
- **THEN** 拒绝并提示「强化+10及以上需要持有对应锻造图纸」

#### Scenario: 有图纸继续强化

- **WHEN** 玩家已学对应图纸并将装备强化到 +10 及以上
- **THEN** 按放大约束的品质分作为成功率执行强化

### Requirement: 里程碑奖励

强化成功达到里程碑等级时 MUST 发放奖励：+5 随机一条已有非特殊词条 +1；+10 随机一条已有词条（含特殊词条）+1；+15 在词条数未达稀有度上限时解锁一条新随机词条。无可加成词条时 MUST NOT 产出奖励且不报错。

#### Scenario: 达到 +5

- **WHEN** 装备强化成功到达 +5 且已有属性词条
- **THEN** 随机一条非特殊词条数值 +1，回复里程碑文案

#### Scenario: 达到 +15

- **WHEN** 装备强化成功到达 +15 且词条数未达上限
- **THEN** 解锁一条新随机词条并回复词缀名与数值

### Requirement: 自动与手动强化

系统 MUST 支持「强化 [装备名/编号]」自动选材强化（+4 以上从背包自动挑选锻材）与「强化 [装备名/编号] [锻材名数量 ...]」手动强化。手动模式 MUST 限制最多 3 种锻材，MUST 校验累计三性落在对应阶段约束内，越界 MUST 报「锻材不满足强化约束」且不扣减；自动模式找不到满足下限的锻材时 MUST 报错且不扣减。装备重名多件时 MUST 列出候选要求用编号精确指定。

#### Scenario: 自动强化

- **WHEN** 玩家发送「强化 寒冰剑」且背包有满足约束的锻材
- **THEN** 系统自动选材并执行本次强化，回复结果与消耗明细

#### Scenario: 手动配比

- **WHEN** 玩家发送「强化 寒冰剑 玄铁矿石3 紫金砂1」且三性落在约束内
- **THEN** 按指定数量扣减锻材并执行强化，回复成功率与结果

#### Scenario: 重名装备

- **WHEN** 玩家输入的名称命中多件装备
- **THEN** 回复候选列表（编号 + 名称 + 稀有度），要求用编号精确指定，不执行强化
