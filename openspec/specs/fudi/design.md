# 福地系统 详细设计

> 行为契约见同目录 spec.md；本文档为详细设计参考。

## 1. 概述

福地是玩家的家园系统：地块经营（灵田 / 兽栏）、地灵互动（对话、好感、送礼）、天劫渡劫。灵兽属性、孵化、进化、繁育、产出等细节见 `openspec/specs/beasts/design.md`，本文只描述福地侧的地块与交互。

> **表名说明**：代码与迁移中的实际表名为 `fudi`、`fudi_cell`、`spirit`、`spirit_form`（无 `xt_` 前缀）。

## 2. 数据模型（以代码 / 迁移为准）

### 2.1 福地表 (fudi)

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | BIGSERIAL | PK |
| `user_id` | BIGINT NOT NULL UNIQUE | 所属用户（FK → player，级联删除） |
| `tribulation_stage` | INTEGER NOT NULL DEFAULT 0 | 当前劫数（每渡过一次天劫 +1，无上限；CHECK ≥ 0） |
| `last_online_time` | TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP | 最后在线（每次访问福地刷新，当前不参与任何判定） |
| `last_tribulation_time` | TIMESTAMP | 上次天劫时间（用于冷却判定） |
| `tribulation_win_streak` | INTEGER NOT NULL DEFAULT 0 | 天劫连胜（CHECK ≥ 0） |
| `create_time` / `update_time` | TIMESTAMP | 时间戳 |

### 2.2 地块表 (fudi_cell)

地块独立成表，每个地块一行。

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | BIGSERIAL | PK |
| `fudi_id` | BIGINT NOT NULL | 所属福地（FK → fudi，级联删除） |
| `cell_id` | INT NOT NULL | 地块编号（从 1 开始，CHECK ≥ 1） |
| `cell_type` | VARCHAR(16) NOT NULL DEFAULT 'EMPTY' | 地块类型：`EMPTY` / `FARM` / `PEN`（大写，CHECK 约束） |
| `cell_level` | INT NOT NULL DEFAULT 1 | 地块等级（CHECK 1~5） |
| `config` | JSONB NOT NULL DEFAULT '{}' | 建筑专有属性（按类型反序列化为 `FarmConfig` / `PenConfig` / `EmptyConfig`） |
| `create_time` / `update_time` | TIMESTAMP | 时间戳 |

唯一约束：`(fudi_id, cell_id)`；索引：`(fudi_id, cell_type)`。

**灵田 config 示例（FarmConfig）**：

```json
{
  "crop_id": 1,
  "plant_time": "2024-01-01T12:00:00",
  "mature_time": "2024-01-02T12:00:00",
  "harvest_count": 0
}
```

| 字段 | 说明 |
|---|---|
| `crop_id` | 作物模板 ID（`item_template.id`） |
| `plant_time` | 种植时间 |
| `mature_time` | 成熟时间 |
| `harvest_count` | 已收获次数（多季作物） |

**兽栏 config 示例（PenConfig）**：

```json
{
  "beast_id": 1,
  "template_id": 5,
  "hatch_time": "2024-01-01T12:00:00",
  "mature_time": "2024-01-02T12:00:00",
  "production_stored": [
    {"template_id": 1, "name": "灵草", "quantity": 5}
  ],
  "last_production_time": "2024-01-02T12:00:00"
}
```

| 字段 | 说明 |
|---|---|
| `beast_id` | 关联灵兽 ID（`beast.id`） |
| `template_id` | 兽卵模板 ID（用于产出配置） |
| `hatch_time` | 孵化开始时间 |
| `mature_time` | 孵化完成时间 |
| `production_stored` | 累积产出列表 JSONB（兼容旧版整数格式，旧格式读取为空列表） |
| `last_production_time` | 上次产出结算时间 |

空地 config 为 `{}`（`EmptyConfig`）。

### 2.3 地灵表 (spirit)

地灵与福地 1:1 绑定。

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | BIGSERIAL | PK |
| `fudi_id` | BIGINT NOT NULL UNIQUE | 所属福地（FK → fudi，级联删除） |
| `form_id` | BIGINT NOT NULL | 形态 ID（FK → spirit_form） |
| `affection` | INTEGER NOT NULL DEFAULT 0 | 好感度（CHECK ≥ 0，上限受 `affection_max` 约束） |
| `affection_max` | INTEGER NOT NULL DEFAULT 1000 | 好感度上限（CHECK > 0） |
| `mbti_type` | VARCHAR(4) NOT NULL | MBTI 人格（CHECK 正则 `^[EI][SN][TF][JP]$`，锁定不可更改） |
| `last_gift_time` | TIMESTAMP | 上次送礼时间（每日限送一次） |
| `create_time` / `update_time` | TIMESTAMP | 时间戳 |

> 源文档中的 `energy`（地灵精力）、`emotion_state`（情绪状态）、`last_energy_update`、`last_event_time` 字段在代码与迁移中**不存在**，相关玩法（精力归零、情绪 EXCITED/FATIGUED/ANGRY）均未实现。

### 2.4 地灵形态表 (spirit_form)

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | BIGSERIAL | PK |
| `name` | VARCHAR(50) NOT NULL UNIQUE | 形态名（如小狐妖、剑灵、老槐树精） |
| `description` | TEXT NOT NULL | 形态描述 |
| `liked_tags` | JSONB NOT NULL DEFAULT '[]' | 喜欢的物品 tag 候选池（GIN 索引） |
| `disliked_tags` | JSONB NOT NULL DEFAULT '[]' | 讨厌的物品 tag 候选池（GIN 索引） |

## 3. 灵石消耗（以代码为准）

| 操作 | 灵石消耗 |
|---|---|
| 建造灵田 | 50 |
| 建造兽栏 | 100 |
| 拆除地块 | 0（不返还建造费） |
| 地块升级 Lv1→Lv2 / Lv2→Lv3 / Lv3→Lv4 / Lv4→Lv5 | 200 / 400 / 800 / 1600 |
| 种植 | 1 颗种子（不再有 `tier × 5` 灵石消耗） |
| 收获 | 无消耗（无「地灵精力 5 点」机制） |
| 天劫 | 无消耗 |
| 地灵送礼 | 1 件物品 |
| 灵兽孵化 / 进化 / 繁育等 | 见 `beasts` 详细设计 |

## 4. 地块类型 (CellType)

| 类型 | code | 作用 |
|---|---|---|
| 空地 | `EMPTY` | 未建造的空地块 |
| 灵田 | `FARM` | 种植灵药 |
| 兽栏 | `PEN` | 孵化 / 饲养灵兽，详见 `beasts` 详细设计 |

## 5. 地块等级与加速系数

灵田和兽栏均有独立等级（Lv1~5）：

| 等级 | 升级消耗 | 累积 | 加速系数（作物等阶 = 1 时） |
|---|---|---|---|
| Lv1 | — | 0 | 1.00× |
| Lv2 | 200 | 200 | 1.15× |
| Lv3 | 400 | 600 | 1.30× |
| Lv4 | 800 | 1400 | 1.45× |
| Lv5 | 1600 | 3000 | 1.60× |

**实际公式**：`加速系数 = 1 + (地块等级 - 作物等阶) × 0.15`。

- 作物等阶由基础生长时间 `grow_time`（小时）推导：≤24 → 1 阶，≤48 → 2 阶，≤72 → 3 阶，≤120 → 4 阶，>120 → 5 阶。
- 种植要求 `灵田等级 ≥ 作物等阶`，否则拒绝（提示需要对应阶数灵田）。
- `cellLevel < minRequired` 时代码会返回 0.5×，但种植路径先抛错，实际不可达。
- 文档表格的 1.00/1.15/1.30/1.45/1.60 仅在作物等阶为 1 时成立。

## 6. 地块扩建

- 初始地块数：**3**（cell_id = 1, 2, 3），注册创建福地时生成。
- 增长公式：`maxCells = 3 + floor(tribulationStage / 3)`（整数除法）。
- 扩建方式：**自动解锁**，无消耗。
- 触发时机：`ensureFudiReady` 时懒加载补齐——即「福地」「福地地块」查询；创建福地时也执行一次。地灵工具的「查询地块」不会补齐。

## 7. 种植系统（灵田）

**定位**：低门槛、快周转、活跃型。

### 7.1 核心公式（以代码为准）

```
种植消耗   = 种子 × 1
基础生长时间 = item_template.grow_time（小时，缺省 5）
生长时间   = max(0.1, 基础生长时间 / 加速系数)
产量       = 模板 properties.growth.yield_min ~ yield_max 随机（缺省 1~3）
每份产出独立判定变异（properties.growth.mutation.chance → 变异模板）
收获消耗   = 无
多季次数   = 模板 properties.growth.max_harvest（缺省 1）
```

### 7.2 收获与多季

- 收获需生长进度 ≥ 1.0（`elapsed / (mature - plant)`）。
- 多季作物（`harvest_count < max_harvest`）：收获后重置生长进度（保留 `harvest_count`），可继续收获，直至达到次数上限后地块清空。
- 单季作物：收获后地块记录被删除（回空地）。
- 批量收取（`collect all`）会一次性处理所有成熟灵田与有产出的兽栏，并回传收获地块数、收取兽栏数与总件数。

### 7.3 枯萎机制

- 普通作物：成熟后超过 `2 × 基础生长时间` 未收 → 枯萎；收取时提示已枯萎并清除该地块。地块展示时枯萎作物标记为不可收取。
- 多季作物免除枯萎检查（`harvest_count < max_harvest` 时 `isWilted` 恒为 false）。

## 8. 兽栏

兽栏承载孵化 / 饲养灵兽，配置存于 `PenConfig`（见 2.2）。孵化、放生、进化、出战 / 召回、产出结算与收取的完整规则见 `beasts` 详细设计；玩家入口统一为地灵对话（`manageBeast` / `breedBeasts` 工具）与「福地地块」展示。

福地侧相关行为：

- 每次访问福地（福地 / 地块 / 地灵交互等 `findAndTouchFudi` 路径）会为未出战的受伤灵兽恢复 1% 最大 HP，并刷新 `last_online_time`。
- 拆除兽栏时解除其中灵兽的 `penned_cell_id` 占用。
- 兽栏地块展示灵兽名、品质、等阶、变异特质、暂存产出、孵化中状态。

## 9. 天劫系统

天劫由 `TribulationService` 处理，通过 `CombatService.buildPlayerTeam()` 构建玩家 + 出战灵兽队伍，调用战斗引擎进行回合制战斗（最大 40 回合）。Boss 属性基于防守方队伍总战力动态缩放。

### 9.1 触发机制

- **主动渡劫**：玩家发送「福地渡劫」，或在地灵对话中要求渡劫（`triggerTribulation` 工具）。
- **冷却**：距上次天劫不足 **1 小时**时拒绝，并返回剩余小时数；冷却中不进入战斗。
- **无强制渡劫**：源文档「距上次劫后 7 天自动触发」未实现；`last_online_time` 仅记录，不参与判定。
- 队伍无存活单位时返回「没有可出战的单位，天劫无法降临」；注意代码在此之前已写入 `last_tribulation_time`，因此仍会进入冷却。

### 9.2 Boss 属性缩放

```
BossHP = 防守方总HP   × (1.0 + 劫数 × 0.5)
Boss攻 = 防守方均攻   × (0.6 + 劫数 × 0.15)
Boss防 = 防守方均防   × (0.4 + 劫数 × 0.10)
Boss速 = 防守方均速   × (0.7 + 劫数 × 0.08)
```

防守方队伍 = 玩家 + 所有出战灵兽。

**怜悯判定**：地灵存在且好感度 ≥ 800 且队伍有存活单位；仅在战败时走怜悯结算（玩家战胜则正常结算）。

### 9.3 战斗结果（以代码为准）

| 结果 | 条件 | 效果 |
|---|---|---|
| **胜利** | 防守方击杀 Boss | 劫数 +1、连胜 +1、灵石奖励 = 新连胜 × 100、好感 +5 |
| **怜悯庇护** | 战败 + 好感 ≥ 800 + 有存活单位 | 劫数 +1、连胜 +1、灵石奖励 = 新连胜 × 100、好感不变 |
| **失败** | 战败 + 好感 < 800 | 劫数与连胜清零（连胜重置为 0）、按比例摧毁地块、好感下降 = 被毁地块数 |

> 源文档的「情绪 → EXCITED / FATIGUED / ANGRY」与「精力归零」均未实现（无对应字段）。

### 9.4 地块摧毁规则

摧毁数量与战斗表现挂钩（Boss 剩余 HP 越少，输得越体面），随机选择被摧毁地块并清空为 `EMPTY`：

| Boss 剩余 HP | 摧毁数量 |
|---|---|
| ≥ 50% | `ceil(60% × 已占用地块数)`，并限制在 1 ~ 已占用数 |
| 20% ~ 50% | `ceil(30% × 已占用地块数)`，并限制在 1 ~ 已占用数 |
| < 20% | 1 块（占用地块数为 0 时为 0） |

## 10. 地灵互动

### 10.1 对话

- 指令：`地灵 内容`（自然语言），由 `SpiritChatService` 处理，对话隔离 key 为 `SPIRIT:userId:fudiId`。
- 系统提示注入：MBTI 人格语气、形态名、劫数、好感度、地块详情；由 LLM 决定调用哪些工具。
- 对话受 `AiChatRateLimiter` 限流；AI 不可用时返回降级文案。

### 10.2 可用工具（玩家可观察的操作入口）

| 工具 | 行为 |
|---|---|
| `checkFudiCells` | 查询地块总数 / 已占用 / 空地编号 |
| `checkPlayerBag` | 按类别查看背包 |
| `plantCrop` | 在灵田播种（名称或种子编号） |
| `buildCell` | 建造灵田 / 兽栏 |
| `removeCell` | 拆除地块 |
| `upgradeCell` | 升级地块 |
| `collectProduce` | 收取单个地块或 `all` 批量收取 |
| `manageBeast` | 孵化 / 放生 / 进化 / 出战召回（见 beasts） |
| `breedBeasts` | 灵兽繁育（见 beasts） |
| `feelOffended` | 地灵表达不满，好感 -1~-5 |
| `acceptGift` | 接受礼物（送礼） |
| `triggerTribulation` | 触发天劫 |

### 10.3 好感度与送礼

- 好感范围 0 ~ 1000（`addAffection` 双向截断）。
- 送礼每日限一次（数据库原子占用今日机会）；礼物按物品 tags 与形态喜欢 / 讨厌 tags 匹配：
  - 命中喜欢：好感 +10 ~ +50，反应「开心」
  - 命中讨厌：好感 -5 ~ -20，反应「嫌弃」
  - 均未命中：好感 +1 ~ +3，反应「平淡」
- 礼物必定消耗 1 件。
- 好感 ≥ 800 影响天劫怜悯；好感也影响灵兽孵化品质下限（见 beasts）。

## 迁移评估：设计取舍

> 原设计文档与实现的差异评估。A 实现现状（文档已按代码修正）；B 保留代码设计（更合乎玩法）；C 按设计修正（设计意图更优，条目标注已修/待修）；D 未实现（待办）；E 缺陷修复。

### A. 实现现状（文档已修正）

- **表名无 `xt_` 前缀**：实际为 `fudi`、`fudi_cell`、`spirit`、`spirit_form`（迁移 V1.0.9 / V1.0.10 / V1.0.16 / V1.0.18）。
- **地块类型取值**：实际为大写 `EMPTY` / `FARM` / `PEN`（DB CHECK 约束），非文档的小写。
- **地灵形态与人格**：注册时随机形态 + 随机 MBTI，人格锁定不可更改，与文档一致。

### B. 保留代码设计

- **地灵收敛为单一好感度轴，不实现精力 / 情绪状态机**：`energy` / `emotion_state` 等字段在代码与迁移中不存在；怜悯由好感门槛（≥800）触发、送礼反应由标签与好感决定，状态可预期，避免隐藏状态造成不可控挫败（怜悯文案残留见 E）。
- **建造收费：灵田 50 / 兽栏 100 灵石，拆除不返还**（文档未写）：形成灵石回收，价格区分两类地块的投入；拆除不返还避免拆建套利。
- **种植只消耗 1 颗种子，不叠加 `tier × 5` 灵石**：灵田定位「低门槛、快周转」，种子获取本身已是门槛，避免高阶作物双重收费。
- **产量按模板 `yield_min ~ yield_max` 随机（缺省 1~3）并逐份判定变异，不叠加 `劫数 / 5`**：劫数无上限（CHECK 仅 ≥0），按劫数加成会让产出无上限膨胀；模板范围可控，变异提供额外惊喜。
- **收获无消耗**：与首条同因，日常收获不应二次收费。
- **多季次数由模板 `max_harvest`（缺省 1）决定，不用 `1 + tier / 3`**：多季是模板显式属性，数据可控；公式化会让所有作物自动多季，产出与收益失控。
- **加速系数以作物等阶为基准**：`1 + (地块等级 - 作物等阶) × 0.15`，且种植要求灵田等级 ≥ 作物等阶；升级既有门槛意义（低级田不能种高阶作物），超配才有加速收益，与递增的升级消耗（200→1600）一致。
- **无强制渡劫**：不实现「距上次劫后 7 天自动触发」，天劫完全主动发起，不让玩家因离线承担损失（与产品「不做主动推送」一致）。
- **主动渡劫 1 小时冷却**：限制天劫频次，防止高连胜玩家反复刷 `连胜 × 100` 灵石奖励（无出战单位误触冷却见 E）。
- **怜悯仅在战败时结算且不改好感**：胜利无需怜悯；好感 ≥800 本身是长期投入门槛，保底不额外扣好感，避免失败叠加惩罚。
- **失败代价与被毁地块数挂钩**：好感下降 = 被毁地块数，摧毁比例 `ceil` 且占用地块 >0 时至少 1 块，代价与损失规模直观对应。
- **福地操作统一走地灵自然语言，不提供固定指令**：固定指令只有 `福地` / `福地地块` / `地灵 内容` / `福地渡劫`，种植、建造、收取、灵兽等全部经对话工具完成，减少指令面，与 spec「MUST NOT 提供对应固定指令」一致。
- **枯萎地块不自动消失、展示时标记不可收取**：给玩家挽回窗口，避免离线期间地块无声损毁（单块收取清除失效见 E）。
