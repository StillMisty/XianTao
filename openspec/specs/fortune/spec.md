# fortune Specification

## Purpose
定义每日运势系统对玩家可观察的行为契约：三维运势的每日刷新与同日确定性、运势等级与点评的展示、主动查询入口，以及运势对掉落数量、悬赏灵石、商店砍价、子事件触发、历练修为与战斗怪物强度的实际影响。运势值不落库、同日恒定；倍率公式与阈值细节见同目录 design.md。

## Requirements

### Requirement: 每日运势生成与送达

系统 MUST 在玩家当日首次以非稳定状态（历练中、旅行中、受伤等）加载角色时生成当日运势事件，并 MUST 在该玩家下一次任意指令回复中自动送达；同一玩家同一日 MUST NOT 重复生成。玩家处于空闲且满血等稳定状态时 MUST NOT 自动生成事件，但玩家仍可主动查询。

#### Scenario: 当日首次状态结算

- **WHEN** 玩家当日首次以非稳定状态加载角色状态
- **THEN** 系统生成一条当日运势事件，随下一次指令回复展示三维运势、等级与点评

#### Scenario: 同日不重复生成

- **WHEN** 玩家当日已收到过运势事件后再次加载状态
- **THEN** 不再生成新的运势事件

#### Scenario: 稳定状态不生成

- **WHEN** 玩家空闲且满血时发送指令
- **THEN** 不自动追加运势事件；玩家可用「今日运势」查询

### Requirement: 主动查询今日运势

系统 MUST 支持玩家通过「今日运势」指令随时查询当日运势。输出 MUST 包含财运、情缘、机缘三个维度的数值与进度条，以及运势等级和一行点评。

#### Scenario: 查询今日运势

- **WHEN** 玩家发送「今日运势」
- **THEN** 回复展示三维数值（0~100）、运势等级（大吉 / 吉 / 平 / 凶 / 大凶）与点评

#### Scenario: 未认证玩家

- **WHEN** 未注册玩家发送「今日运势」
- **THEN** 系统按未认证处理并引导注册，不展示运势

### Requirement: 运势数值确定性与每日刷新

运势三维数值 MUST 由玩家 ID 与日期确定性生成，取值 0~100；同一玩家在同一日内任意次查询 MUST 完全一致，跨日 MUST 重新生成。运势值 MUST NOT 持久化到数据库，仅记录生成日期以避免重复生成。

#### Scenario: 同日恒定

- **WHEN** 玩家在同一天多次查询今日运势
- **THEN** 各次的三维数值、等级与点评完全一致

#### Scenario: 跨日刷新

- **WHEN** 日期变更后玩家再次查询
- **THEN** 系统按新日期生成一组新的运势值

### Requirement: 运势等级与点评

系统 MUST 依据三维数值判定五档运势：大吉（三项均 ≥80）、大凶（三项均 <40）、吉（最高 ≥80 且最低 ≥45）、凶（最低 <25）、平（其余）。点评 MUST 按维度高低组合生成；凶日与大凶日的点评 MUST 给出「谨言慎行」「宜闭关静修」等引导，而非纯负面提示。

#### Scenario: 大吉

- **WHEN** 三维数值均不低于 80
- **THEN** 等级显示「大吉」，点评为鼓励大胆行事的正面文案

#### Scenario: 大凶

- **WHEN** 三维数值均低于 40
- **THEN** 等级显示「大凶」，点评引导玩家闭关静修

#### Scenario: 单一维度突出

- **WHEN** 某维度数值 ≥80 而其余维度平平
- **THEN** 等级不为大吉，点评体现该维度的正面词（如「财源广进」）

### Requirement: 财运影响掉落、悬赏与砍价

财运 MUST 影响掉落物数量、悬赏灵石奖励与商店砍价。财运倍率 MUST 在约 0.85×~1.15× 之间；掉落数量 MUST 只增不减（不低于基础数量）；悬赏灵石结算 MUST 乘以财运倍率；商店砍价的成功率与让价幅度 MUST 受财运倍率影响。

#### Scenario: 财运高时掉落更多

- **WHEN** 玩家财运数值为高值并击杀有掉落的怪物
- **THEN** 掉落物品数量按财运倍率上浮，掉率判定不受影响

#### Scenario: 悬赏结算

- **WHEN** 玩家完成悬赏并结算灵石奖励
- **THEN** 最终灵石乘以财运倍率后入账

### Requirement: 情缘影响子事件触发

情缘 MUST 影响旅行、历练、悬赏中的子事件触发概率，倍率 MUST 在约 0.70×~1.30× 之间；调整后的触发概率 MUST 被限制在 0~1。

#### Scenario: 情缘高时更容易触发子事件

- **WHEN** 玩家情缘数值为高值并进行历练、旅行或悬赏结算
- **THEN** 子事件触发概率按情缘倍率上调，且不超过 100%

#### Scenario: 情缘低时子事件减少

- **WHEN** 玩家情缘数值为低值并进行上述结算
- **THEN** 子事件触发概率按情缘倍率下调，不低于 0%

### Requirement: 机缘影响历练修为与战斗怪物

机缘 MUST 影响历练修为收益与战斗怪物等级。历练修为 MUST 乘以机缘倍率（约 0.80×~1.20×）；怪物等级 MUST 按机缘偏移调整（机缘高时偏移为负、机缘低时偏移为正），偏移后等级 MUST NOT 低于 1。

#### Scenario: 机缘高时历练收益增加

- **WHEN** 玩家机缘数值为高值并完成历练结算
- **THEN** 历练修为按机缘倍率上浮

#### Scenario: 机缘低时怪物更强

- **WHEN** 玩家机缘数值为低值并进入战斗
- **THEN** 怪物等级按正偏移提升，战斗强度增加
