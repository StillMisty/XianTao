# game-features Specification

## Purpose
记录当前已可玩的玩法与指令基线（22 个命令组 / 71 条指令 + AI 对话），作为后续功能变更的对照起点。每条需求描述玩家可观察到的能力与关键引导行为；数值平衡细节不在本规格内。

## Requirements

### Requirement: 角色与成长

系统 MUST 提供注册（我要修仙）、状态、突破、护道（建立/解除/查询）、改号、查看、排行榜（修为/灵石）。新玩家注册后 MUST 得到「状态」与「背包」的引导；修为不足时突破 MUST 提示所需修为；修为圆满时状态 MUST 显示「可突破」。

#### Scenario: 新玩家注册

- **WHEN** 新玩家发送「我要修仙 道号」
- **THEN** 收到欢迎语、道号确认与下一步引导

#### Scenario: 修为不足突破

- **WHEN** 玩家修为不足时发送「突破」
- **THEN** 提示所需修为、当前修为与成功率，不产生扣减

### Requirement: 探索与历练

系统 MUST 提供地图（当前地图信息 + 四方可达 + 可前往地区按钮）、前往、历练、历练结算、悬赏（列表/接取/结算/放弃）、世界事件（列表/参与）、今日运势。不适宜历练的地图 MUST 给出原因与建议目的地；历练结算 MUST 展示实际收益或明确无收益。

#### Scenario: 地图与旅行

- **WHEN** 玩家发送「地图」
- **THEN** 展示当前地图、妖兽、相邻地区（含御剑时长）与「前往 X」按钮

#### Scenario: 不适宜历练的引导

- **WHEN** 玩家在非试炼之地发送「历练」
- **THEN** 提示原因并建议前往相邻的试炼之地

### Requirement: 战斗与装备

系统 MUST 提供切磋、装备穿戴/卸下、丢弃、强化、锻造（列表/锻造/强化）。强化重名装备时 MUST 列出候选而非报「未找到」；锻造/强化消耗的材料与灵石 MUST 在回复中可见。

#### Scenario: 强化重名装备

- **WHEN** 背包中存在多件同名装备时发送「强化 名称」
- **THEN** 列出候选装备（编号/品质）供选择

### Requirement: 炼丹与物品

系统 MUST 提供背包（分类查看）、使用、丹方（列表/详情）、炼方（按丹方自动炼丹）、炼（手动配比）。未学习卷轴时直接炼方 MUST 提示先「使用」卷轴；五行属性错误 MUST 以中文（金/木/水/火/土）提示缺失属性。

#### Scenario: 未学习卷轴直接炼方

- **WHEN** 背包中有丹方卷轴但未学习时发送「炼方 卷轴名」
- **THEN** 提示「背包中有同名卷轴，请先『使用 X』学习」

#### Scenario: 五行不匹配

- **WHEN** 药材属性不满足丹方要求
- **THEN** 以中文提示缺少的属性（如「缺少药材属性：金」）

### Requirement: 社交

系统 MUST 提供师徒（拜师/收徒/师徒查询/逐出师门/叛师）与宗门（创建/状态/退出/解散）与宗灵对话。拜师 MUST 要求对方境界高至少一个大境界，未满足时 MUST 说明门槛与「护道」替代；护道 MUST 允许任意道友互结并展示加成。

#### Scenario: 新号拜师被拒

- **WHEN** 境界相同的两名玩家尝试拜师/收徒
- **THEN** 提示「师傅境界必须高于你至少一个大境界」；师徒空态同时给出护道替代引导

### Requirement: 福地与秘境

系统 MUST 提供福地（状态/地块/地灵对话/渡劫）与秘境（列表/进入/秘灵对话）。秘境列表 MUST 展示入口位置与暂不可入的原因（境界或位置）；未在秘境时「秘境」MUST 展示列表而非仅状态文案。

#### Scenario: 秘境列表可发现

- **WHEN** 玩家在任意地点发送「秘境」
- **THEN** 列出可用秘境及其入口、等级区间、奖励进度与暂不可入原因

#### Scenario: 地灵与福地经营

- **WHEN** 玩家与地灵对话要求种植/建造
- **THEN** 地灵通过工具调用完成操作并回报地块状态

### Requirement: 商铺交易

系统 MUST 提供商铺对话（掌柜）与快速回收（回收）。买卖 MUST 通过掌柜的自然语言工具调用完成；玩家不在商铺所在地时 MUST 提示「此地没有商铺掌柜」。AI 空回复 MUST 有兜底文案，不得发送空消息。

#### Scenario: 快速回收

- **WHEN** 玩家发送「回收 物品名」
- **THEN** 掌柜估价并完成回收，回复成交叙述与灵石变化

#### Scenario: 无商铺位置

- **WHEN** 玩家在无商铺的地图与掌柜对话
- **THEN** 提示此地没有商铺掌柜

### Requirement: AI 对话能力

系统 MUST 提供 AI 驱动的 NPC 对话：地灵（福地经营工具）、秘灵（秘境探索）、宗灵（宗门）、掌柜（交易工具）。AI 不可用或返回空时 MUST 使用领域化降级文案（如「地灵暂时无法回应」），MUST NOT 暴露内部字段名或英文键。

#### Scenario: AI 不可用降级

- **WHEN** AI 服务超时或返回空
- **THEN** 玩家收到该 NPC 的降级文案，指令链路不报错

### Requirement: 管理员能力

GM 指令（帮助/给灵石/给修为/治疗/复活/等级/传送/给物品）MUST 仅对 GM 玩家可用；非 GM 调用 MUST 被拒绝并提示。

#### Scenario: 非 GM 越权

- **WHEN** 普通玩家发送「GM给灵石 …」
- **THEN** 回复「你不是 GM，无法执行 GM 指令」

### Requirement: 指令易用性

系统 MUST 在缺参时给出用法提示（「X」还需要补充内容，输入「帮助 X」查看用法）；帮助搜索 MUST 对错别字给出近似建议；「查看」MUST 支持查看玩家档案（道号/境界/所在地/状态）；未注册玩家发任意消息 MUST 得到注册引导。

#### Scenario: 缺参提示

- **WHEN** 玩家只发送「前往」「装备」「回收」「使用」等缺参命令
- **THEN** 收到用法提示而非静默

#### Scenario: 帮助纠错

- **WHEN** 玩家发送「帮助 修练」（错别字）
- **THEN** 回复「未找到…你是不是想找：修炼、历练」
