# skills Specification

## Purpose
定义法决系统对玩家可观察的行为契约：法决查询、法决玉简学习、战斗槽位装载与卸下、战斗自动施放、法器绑定约束、效果类型与获取途径。数值公式、效果参数与数据模型见同目录 design.md。

## Requirements

### Requirement: 法决查询

系统 MUST 提供「法决」查询：展示当前已装载法决详情（效果、绑定、调息、境界要求）与已学法决编号列表（已装载标记）。未装载任何法决时 MUST 提示；未学会任何法决时 MUST 引导「使用 [玉简名称]」习得。

#### Scenario: 查询已学法决

- **WHEN** 玩家发送「法决」
- **THEN** 回复分别展示已装载法决与已学法决列表

#### Scenario: 空态引导

- **WHEN** 玩家尚未学会任何法决时发送「法决」
- **THEN** 回复提示并引导使用法决玉简

### Requirement: 法决玉简学习

系统 MUST 支持「使用 [玉简名]」习得对应法决。学习 MUST 校验：背包持有该玉简、玉简对应法决存在、玩家未学过、境界达到法决要求。成功后 MUST 消耗 1 件玉简并加入已学法决（默认未装载）；失败 MUST 说明原因且不消耗玉简。名称不匹配时 MUST 列出玩家持有的玉简供参考。

#### Scenario: 成功习得

- **WHEN** 玩家使用未学过的法决玉简且境界达标
- **THEN** 回复习得成功并展示法决详情，玉简数量减 1

#### Scenario: 重复学习

- **WHEN** 玩家使用已学会法决的玉简
- **THEN** 回复「你已经学会…了」，玉简不消耗

#### Scenario: 境界不足

- **WHEN** 玩家境界低于法决要求
- **THEN** 回复所需境界与当前境界，玉简不消耗

### Requirement: 战斗槽位装载

系统 MUST 支持「法决装载 [名称/编号]」把已学法决放入槽位。槽位上限 MUST 按等级：初始 1、20 级 2、40 级 3、60 级 4、80 级 5。未学过 MUST 提示先学习；已在槽位 MUST 提示；槽位已满 MUST 提示当前占用并要求先卸下。装载 MUST 防止并发超额。

#### Scenario: 装载成功

- **WHEN** 玩家在有空余槽位时发送「法决装载 御剑术」
- **THEN** 法决进入槽位并回复槽位占用情况

#### Scenario: 槽位已满

- **WHEN** 已装载数达到当前等级上限时再次装载
- **THEN** 回复槽位已满（N/N），不改变装载状态

### Requirement: 战斗槽位卸下

系统 MUST 支持「法决卸下 [名称/编号]」从槽位卸下法决。当前无装载时 MUST 提示；输入不匹配已装载法决时 MUST 提示并引导使用「法决」查看。

#### Scenario: 卸下成功

- **WHEN** 玩家发送「法决卸下 御剑术」
- **THEN** 该法决被移出槽位并回复剩余槽位情况

### Requirement: 战斗自动施放

战斗中系统 MUST 只施放已装载且冷却完成的法决，各法决 MUST 独立冷却；冷却回合数 MUST 由法决调息与当前法器攻速共同决定。行动者被沉默时 MUST NOT 施放法决。法决全部效果均未命中/生效时 MUST 退化为普通攻击且 MUST NOT 进入冷却。

#### Scenario: 冷却完成自动施放

- **WHEN** 战斗回合推进且已装载法决冷却结束
- **THEN** 战斗日志出现该法决的施放与效果结算，随后进入冷却

#### Scenario: 沉默中

- **WHEN** 玩家被沉默且轮到其行动
- **THEN** 该回合只进行普通攻击，不施放法决

### Requirement: 法器绑定约束

法决绑定类型 MUST 分为 NONE、WEAPON_TYPE、WEAPON_CATEGORY、ELEMENT。WEAPON_TYPE MUST 要求当前装备法器子类型与绑定值精确一致；WEAPON_CATEGORY MUST 按法器大类匹配；ELEMENT 为预留（当前恒通过）；NONE MUST 对任何法器生效。组队时绑定不匹配的法决 MUST 被排除，不进入战斗技能列表；未装备法器时绑定类法决 MUST 不生效。

#### Scenario: 类型绑定不匹配

- **WHEN** 玩家装载了绑定「剑」的法决但装备刀进入战斗
- **THEN** 该法决不参与战斗施放

#### Scenario: 无绑定

- **WHEN** 玩家装载 NONE 绑定法决且任意法器（或空手）
- **THEN** 该法决正常参与战斗

### Requirement: 效果类型

法决效果 MUST 覆盖伤害、控制、辅助三类；伤害/治疗公式 MUST 支持 `attack`、`wis`、`str`、`agi` 变量与四则运算及括号。效果带 `chance` 时 MUST 按概率判定；未生效的效果 MUST NOT 造成伤害/控制/增益。被动预留效果（抗性/气血/濒死生存）MUST NOT 进入主动施放结算。

#### Scenario: 概率控制

- **WHEN** 法决带 `STUN` 效果且 `chance=0.4`
- **THEN** 每次施放按 40% 概率使目标跳过行动，未触发时无控制效果

#### Scenario: 公式伤害

- **WHEN** 法决公式为 `wis*3+20`
- **THEN** 伤害按玩家悟性代入公式计算，并叠加克制/增益倍率

### Requirement: 法决获取途径

系统 MUST 提供至少三种获取途径：法决玉简使用、历练顿悟、宗门共享功法。历练顿悟 MUST 按悟性触发，从满足悟性要求、境界要求且无前置法决的可学法决中随机习得（不消耗物品）；宗门共享功法 MUST 消耗宗门贡献且校验境界与是否已学。

#### Scenario: 历练顿悟

- **WHEN** 历练结算触发顿悟且玩家悟性满足某法决要求
- **THEN** 玩家随机习得该法决并收到叙事提示

#### Scenario: 宗门学习

- **WHEN** 玩家在宗门以贡献兑换共享功法且境界达标、未学过
- **THEN** 扣除贡献并加入已学法决

### Requirement: 法决详情查看

系统 MUST 支持「查看 [玉简名]」展示玉简对应法决：名称、类型（主动/被动）、效果说明、绑定类型与绑定值、调息秒数、境界要求与描述。

#### Scenario: 查看玉简

- **WHEN** 玩家发送「查看 御剑术玉简」
- **THEN** 回复展示该法决的类型、效果、绑定、调息与境界要求
