# combat Specification

## Purpose
定义通用战斗引擎的行为契约：懒结算模拟、行动顺序与技能选择、技能效果与 Buff/Debuff、受击反应、伤害与法器克制、玩家/灵兽参战、怪物缩放与掉落、动态遇怪、高光战斗与战后结算。具体公式与实现细节见同目录 design.md。

## Requirements

### Requirement: 战斗模拟与结果

所有战斗 MUST 在服务端一次性模拟完成，无实时交互、无后台任务。结果 MUST 包含胜方、实际回合数与完整战斗日志；达到回合上限仍未分出胜负时 MUST 判定为平局（DRAW）。

#### Scenario: 一场完整战斗

- **WHEN** 历练遇敌或发起切磋
- **THEN** 系统一次模拟整场战斗，返回胜方、回合数与逐次出手的战斗日志

#### Scenario: 超时平局

- **WHEN** 双方在回合上限内均未全灭
- **THEN** 结果判定为平局，双方按当前状态结算

### Requirement: 行动顺序与技能选择

每回合 MUST 按速度（含减速/加速修正）降序行动；被控制的单位 MUST 跳过行动；被沉默的单位 MUST NOT 使用技能；有可用技能时 MUST 随机选择一个使用，无可用技能时 MUST 进行普通攻击。

#### Scenario: 被控制跳过行动

- **WHEN** 单位处于眩晕或冰冻状态
- **THEN** 该单位本回合跳过行动并记录为受控

#### Scenario: 被沉默只能普攻

- **WHEN** 单位处于沉默状态且拥有技能
- **THEN** 该单位不能使用技能，只能普通攻击

### Requirement: 技能效果与 Buff/Debuff

系统 MUST 支持伤害、连击、群体伤害、破甲、减速、持续伤害、斩杀、吸血、治疗、攻击/防御/速度增益、眩晕、冰冻、沉默、闪避、反击、反射与净化等效果。持续伤害与治疗 MUST 在回合开始结算；控制效果 MUST 覆盖完整的跳过回合。

#### Scenario: 破甲降低防御

- **WHEN** 目标被施加破甲
- **THEN** 其受到的伤害减免按破甲比例降低，持续指定回合

#### Scenario: 持续伤害结算

- **WHEN** 目标身上存在持续伤害效果
- **THEN** 每回合开始按层数扣除气血，到期后移除

#### Scenario: 冰冻易伤

- **WHEN** 目标处于冰冻状态并受到攻击
- **THEN** 本次伤害被放大，且目标在冰冻期间跳过行动

### Requirement: 受击反应

伤害落地时系统 MUST 依次结算冰冻易伤、闪避、扣血、反伤与反击：闪避成功 MUST 使本次攻击完全落空；反伤 MUST 按比例返还伤害；反击 MUST 概率对攻击者追加一次普通攻击。

#### Scenario: 闪避攻击

- **WHEN** 防守方拥有闪避效果且触发判定
- **THEN** 本次攻击伤害为 0 并记录为闪避

#### Scenario: 反伤与反击

- **WHEN** 防守方拥有反射或反击效果
- **THEN** 攻击者按比例受到返还伤害，或被追加一次普攻伤害

### Requirement: 伤害计算与法器克制

伤害 MUST 按「攻击 × 克制倍率 × 攻击修正 − 防御减免」计算，且 MUST 至少造成 1 点伤害。法器类型克制对应怪物类型时 MUST 造成 ×1.5 伤害，克制 MUST 仅对玩家攻击怪物生效。

#### Scenario: 法器克制

- **WHEN** 玩家以刀攻击妖兽类怪物
- **THEN** 本次伤害获得 ×1.5 克制加成

#### Scenario: 最低伤害

- **WHEN** 防御减免高于或接近攻击方输出
- **THEN** 最终伤害仍为 1 点，不会出现 0 或负数

### Requirement: 玩家与灵兽参战

玩家 MUST 自动参战且不可离队，气血归零 MUST 进入濒死并判全队失败。灵兽 MUST 满足「已出战、气血 > 0、未在休养」才可参战，出战上限 MUST 为 2 只，可正常使用技能且无独立 AI。灵兽阵亡 MUST 取消出战并进入按品质计时的休养期，休养期间 MUST NOT 出战。

#### Scenario: 灵兽出战上限

- **WHEN** 玩家已出战 2 只灵兽后尝试再派出一只
- **THEN** 系统拒绝并提示出战已达上限

#### Scenario: 灵兽阵亡休养

- **WHEN** 出战灵兽在战斗中气血归零
- **THEN** 该灵兽取消出战并按品质进入对应时长的休养

#### Scenario: 玩家全灭

- **WHEN** 玩家方全部单位阵亡
- **THEN** 战斗判负，玩家进入濒死状态

### Requirement: 怪物缩放与掉落

怪物 MUST 由模板与等级缩放生成，实例等级 MUST 在模板基准附近波动；掉落 MUST 按掉落表逐条独立概率判定并分发到背包；战斗修为 MUST 按怪物与玩家的等级差修正。

#### Scenario: 怪物掉落

- **WHEN** 玩家击杀怪物且掉落判定命中
- **THEN** 装备或物品按判定结果进入背包，回复中可见掉落名称与数量

#### Scenario: 等级差修为修正

- **WHEN** 玩家击杀高于或低于自身等级的怪物
- **THEN** 获得修为按等级差修正（有上下限），并受修为存储上限截断

### Requirement: 动态遇怪

遇怪间隔 MUST 依据地图凶险度、等级偏差与地图富裕度计算，并 MUST 控制在 3 到 20 分钟之间；系统 MUST 按间隔与历练时长掷骰决定触发次数，间隔越短单次触发概率越高。

#### Scenario: 地图与等级影响间隔

- **WHEN** 玩家在高等级或等级不匹配的地图历练
- **THEN** 遇怪间隔相应缩短或延长，落在允许区间内

#### Scenario: 触发战斗

- **WHEN** 一段历练时间的掷骰命中战斗事件
- **THEN** 进入一场遇怪战斗并累计到本次结算

### Requirement: 高光战斗

长回合、势均力敌或技能多样的战斗 MUST 被标记为高光战斗，供叙事美化渲染；每次结算至多保留一场高光战斗的完整日志。

#### Scenario: 长回合高光

- **WHEN** 一场战斗达到长回合阈值
- **THEN** 标记为高光并保留其战斗日志用于叙事

#### Scenario: 技能纷呈高光

- **WHEN** 一场战斗触发多种不同技能
- **THEN** 标记为高光并保留其战斗日志用于叙事

### Requirement: 战后结算

历练遇怪战斗结束后 MUST 回写玩家与灵兽气血；玩家全灭 MUST 进入濒死；MUST 处理灵兽休养/觉醒、掉落分发与历练收益结算。重伤中断时，重伤前所获修为与物品 MUST 照常发放。

#### Scenario: 玩家全灭进濒死

- **WHEN** 玩家方在历练战斗中全灭
- **THEN** 玩家进入濒死，历练中断并结算已获得的收益

#### Scenario: 战后收益

- **WHEN** 玩家在历练中获胜
- **THEN** 修为与掉落入账，灵兽气血与休养状态被更新

### Requirement: 玩家战斗属性构成

玩家战斗单位的攻击、防御与速度 MUST 由有效四维、已穿戴装备加成与生效 Buff 共同构成：

```
玩家攻击 = (有效力道 + 装备力道) × 2 + 装备总攻击 + 攻击 Buff 总和
玩家防御 = (有效根骨 + 装备根骨) + 装备总防御 + 防御 Buff 总和
玩家速度 = (有效身法 + 装备身法) × 2 + 10 + 速度 Buff 总和
```

装备加成 MUST 取自已穿戴装备的最终值（含品质波动、随机词条与锻造强化），且 MUST 与「状态」「查看」展示共用同一聚合口径。

#### Scenario: 装备参与战斗

- **WHEN** 玩家穿戴提供四维与攻击/防御加成的装备参战
- **THEN** 其战斗攻击/防御按上式计入装备四维与装备总攻/总防，高于卸下装备时

#### Scenario: 装备口径一致

- **WHEN** 玩家更换为属性更高的装备
- **THEN** 「状态」展示与战斗计算按同一装备聚合同步变化，不出现两处数值口径不一致
