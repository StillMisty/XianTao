# Spec Delta

## Purpose

定义宗门系统对玩家可观察的行为契约：宗门创建与总览、宗灵对话与权限分级、成员进出、贡献与商店、共享功法、建筑与升级。数值公式、数据模型与未实现设计见同目录 design.md。

## ADDED Requirements

### Requirement: 宗门创建

系统 MUST 提供「宗门创建 [名称] [道统描述?]」：要求玩家达到金丹期、未加入任何宗门、名称未被占用，并 MUST 消耗 5000 灵石。创建后宗门 MUST 为 Lv.1、成员上限 10、初始资金 2000，创建者 MUST 成为宗主。系统 MUST 由 LLM 依据名称与道统生成诗号、道统与宗灵人格，LLM 失败时 MUST 回退默认身份且不阻断创建。成功回复 MUST 包含宗门名与诗号。

#### Scenario: 创建成功

- **WHEN** 金丹期玩家以「宗门创建 青云宗 以剑入道」创建宗门
- **THEN** 扣除 5000 灵石并创建宗门，回复宗门名、诗号与初始资金

#### Scenario: 境界不足

- **WHEN** 未达金丹期的玩家尝试创建宗门
- **THEN** 回复创建需要金丹期，不扣灵石

#### Scenario: 名称占用或已有宗门

- **WHEN** 玩家使用已被占用的名称创建，或已加入其他宗门
- **THEN** 回复对应失败原因，不扣灵石

### Requirement: 宗门总览

系统 MUST 提供「宗门」查询：展示宗门名称、品阶、宗主、成员数/上限、资金、我的贡献、我的职位、公告与成员列表（含每人职位与境界）。未加入宗门的玩家 MUST 收到未入宗提示。

#### Scenario: 查看总览

- **WHEN** 已入宗玩家发送「宗门」
- **THEN** 回复宗门名、品阶、宗主、成员、资金、我的贡献/职位与成员列表

#### Scenario: 未入宗

- **WHEN** 未加入任何宗门的玩家发送「宗门」
- **THEN** 回复未在任何宗门中的提示

### Requirement: 宗灵对话与权限分级

系统 MUST 提供「宗灵 [自然语言]」入口，仅宗门成员可用；所有宗门事务 MUST 通过宗灵自然语言完成。宗灵可用权柄 MUST 按调用者职位分级注册：弟子可查商店/功法/建筑、兑换、学习、提交玉简、捐献；长老额外可邀请、踢人、发布公告、上下架功法与商店商品；宗主额外可任免、升级宗门、扩容、建造与升级建筑。低职位 MUST NOT 越权调用高职位权柄。LLM 失败时 MUST 返回「宗灵暂时无法回应，请稍后再试。」。非成员对话 MUST 被拒绝。

#### Scenario: 弟子日常事务

- **WHEN** 弟子对宗灵说「商店有什么好东西」
- **THEN** 宗灵返回贡献商店商品与个人贡献

#### Scenario: 弟子越权被拒

- **WHEN** 弟子要求宗灵「升级宗门」
- **THEN** 请求被拒绝，宗门等级与资金不变

#### Scenario: 非成员

- **WHEN** 未入宗玩家发送「宗灵 你好」
- **THEN** 回复未在任何宗门中的提示

### Requirement: 邀请加入

系统 MUST 仅允许宗主/长老通过宗灵邀请玩家入宗；玩家 MUST NOT 自行申请。邀请 MUST 校验：目标存在、目标没有宗门成员记录（含退宗记录）、宗门未满员。邀请成功即入宗（无接受确认），MUST 以弟子身份加入。

#### Scenario: 邀请成功

- **WHEN** 长老对宗灵说「邀请王五入宗」且王五无宗门记录、宗门未满
- **THEN** 王五立即以弟子身份加入宗门

#### Scenario: 目标已有所属

- **WHEN** 邀请已加入其他宗门（或存在退宗记录）的玩家
- **THEN** 邀请失败并说明原因

#### Scenario: 宗门已满

- **WHEN** 成员数已达上限时邀请
- **THEN** 邀请失败并提示上限人数

### Requirement: 退出、踢出与解散

成员 MUST 可通过「宗门退出」退出；宗主在宗门还有其他成员时 MUST NOT 退出（须解散）。宗主/长老 MUST 可踢出职位低于自己的成员，MUST NOT 踢出自己、宗主或同职位/上级。退出与被踢 MUST 清零贡献、遗忘全部宗门共享功法，并留下退宗记录（该玩家后续无法再被邀请）。「宗门解散」MUST 仅宗主可用，解散 MUST 清除成员、商店商品、共享功法与建筑，并让所有成员遗忘共享功法。

#### Scenario: 主动退出

- **WHEN** 弟子发送「宗门退出」
- **THEN** 退出成功，贡献清零，已学共享功法被遗忘

#### Scenario: 宗主带成员退出

- **WHEN** 宗主在宗门还有成员时发送「宗门退出」
- **THEN** 退出被拒绝并提示剩余成员数

#### Scenario: 解散宗门

- **WHEN** 宗主发送「宗门解散」
- **THEN** 宗门及其成员、商店、功法、建筑全部清除，回复解散成功

### Requirement: 职位任免与宗主传承

宗主 MUST 可通过宗灵任命成员为长老或降为弟子。宗主 MUST 可将宗主之位传给同宗成员：原宗主 MUST 自动降为长老，宗门宗主记录 MUST 同步更新；目标已是宗主时 MUST 提示无需传承。

#### Scenario: 任命长老

- **WHEN** 宗主对宗灵说「任命张三为长老」
- **THEN** 张三职位变为长老

#### Scenario: 宗主传承

- **WHEN** 宗主对宗灵说「任命李四为宗主」
- **THEN** 李四成为宗主，原宗主降为长老

### Requirement: 捐献灵石

成员 MUST 可通过宗灵捐献灵石换取贡献：捐献数量 MUST 大于 0，贡献 MUST 增加 `捐献量 × 0.1`（向下取整），宗门资金 MUST 增加等额灵石；扣减与累加 MUST 原子执行，失败时不得只扣一边。

#### Scenario: 捐献成功

- **WHEN** 成员对宗灵说「我要捐 5000 灵石」
- **THEN** 扣除 5000 灵石，个人贡献 +500，宗门资金 +5000

#### Scenario: 非法数量

- **WHEN** 成员要求捐献 0 或负数灵石
- **THEN** 捐献被拒绝，灵石、贡献与资金不变

### Requirement: 贡献商店

成员 MUST 可查看贡献商店（商品、价格、库存、我的贡献）并消耗贡献兑换商品；兑换 MUST 同时校验贡献充足与库存充足，并原子扣减贡献与库存。宗主/长老 MUST 可上架商品并定价、设置库存（`-1` 表示无限）；定价 MUST 为正数、库存 MUST 为正数或 -1；同一物品重复上架 MUST 更新定价与库存。药园建筑 MUST 按其等级自动向商店上架对应品阶灵药并补满库存。

#### Scenario: 兑换成功

- **WHEN** 成员贡献充足时兑换有库存的商品
- **THEN** 扣除贡献与库存，物品进入背包

#### Scenario: 贡献或库存不足

- **WHEN** 成员贡献低于售价或商品售罄时兑换
- **THEN** 兑换失败，贡献与库存不变

#### Scenario: 上架商品

- **WHEN** 长老对宗灵说「上架灵芝，15 贡献，无限库存」
- **THEN** 商品出现在贡献商店，库存标记为无限

### Requirement: 共享功法

成员 MUST 可提交背包中的功法玉简：消耗 1 件玉简，获得 300 贡献，功法以「待上架」入库；同一功法 MUST NOT 重复提交；提交与上架 MUST 受宗门功法位上限约束（基础 3 + 藏经阁每级 +3）。宗主/长老 MUST 可上架（待上架→已上架）与下架（已上架→待上架，已学者不受影响）。成员学习 MUST 校验功法已上架、未学过、境界达标，并 MUST 消耗 `功法等级要求 × 50` 贡献。学习他人呈献的功法时，学费的 15%（至少 1）MUST 回流给仍在该宗的呈献者并通知之；自学者与已离宗者不回流。退出/被踢/宗门解散后，玩家已学的宗门共享功法 MUST 自动遗忘。

#### Scenario: 提交玉简

- **WHEN** 成员对宗灵说「我要提交一本功法」并持有对应玉简
- **THEN** 玉简被消耗，功法以待上架入库，贡献 +300

#### Scenario: 学习与传功香火

- **WHEN** 成员学习他人呈献的已上架功法且贡献与境界达标
- **THEN** 扣除 `等级要求 × 50` 贡献，功法加入已学，呈献者获得至少 1 点香火并收到通知

#### Scenario: 退宗遗忘

- **WHEN** 成员退出宗门或被踢出
- **THEN** 其已学的全部宗门共享功法被删除，功法仍保留在宗门供他人学习

### Requirement: 宗门升级与扩容

宗主 MUST 可消耗宗门资金提升宗门等级：Lv.1→2 消耗 5000、Lv.2→3 消耗 15000、Lv.3→4 消耗 30000、Lv.4→5 消耗 50000，每次升级成员上限 +5，等级上限 Lv.5。宗主 MUST 可消耗 2500 资金（5 槽 × 500）独立扩充 5 个成员槽位。资金不足时 MUST 拒绝且不改变等级/上限。

#### Scenario: 升级宗门

- **WHEN** 宗主在资金充足时升级宗门
- **THEN** 扣除对应资金，等级 +1，成员上限 +5

#### Scenario: 资金不足

- **WHEN** 宗门资金低于升级费用时升级
- **THEN** 升级被拒绝，等级与资金不变

### Requirement: 宗门建筑

宗主 MUST 可消耗宗门资金建造/升级建筑，每类建筑每宗 MUST 只有一座，升级费用 MUST 等于建造费用。建筑效果 MUST 对成员生效：藏经阁每级 +3 共享功法位；灵脉按 `小时 × 等级 × 100 / 24` 惰性结算注入宗门资金；药园按等级自动上架灵药（Lv.1 灵芝/茯苓 15 贡献、Lv.2 血参/金银花 40、Lv.3 雪莲/紫丹参 60，每级补 10 份）。重复建造 MUST 被拒绝；达到最大等级 MUST 无法继续升级。

#### Scenario: 建造藏经阁

- **WHEN** 宗主建造藏经阁
- **THEN** 扣除 3000 资金，共享功法位上限提升 3

#### Scenario: 建造药园

- **WHEN** 宗主建造药园
- **THEN** 贡献商店自动上架灵芝与茯苓并补满库存

#### Scenario: 重复建造

- **WHEN** 对已建造的建筑再次执行建造
- **THEN** 建造被拒绝，资金不变

### Requirement: 宗门公告

宗主/长老 MUST 可发布宗门公告，公告 MUST 覆盖旧公告；空公告 MUST 被拒绝；公告长度 MUST 受限，超长内容 MUST 被截断。公告 MUST 在宗门总览与宗灵上下文中可见。

#### Scenario: 发布公告

- **WHEN** 长老对宗灵说「发布公告：今日宗门大比」
- **THEN** 公告更新，宗门总览展示新公告

#### Scenario: 弟子越权

- **WHEN** 弟子尝试发布公告
- **THEN** 请求被拒绝，公告不变
