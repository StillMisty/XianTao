# Spec Delta

## Purpose

定义物品与装备系统对玩家可观察的行为契约：背包查看与分类、装备穿戴/卸下、物品丢弃、装备实例生成（稀有度/词条/属性）、法器克制、堆叠与自动入包、统一物品使用。公式、数据模型与配置细节见同目录 design.md。

## ADDED Requirements

### Requirement: 背包查看与分类

系统 MUST 提供「背包」汇总查询（未穿戴装备、按类型物品、灵石）与「背包 [分类]」分类编号列表；分类 MUST 支持种子、装备、兽卵、锻材、丹药、药材、法决玉简、丹方卷轴、锻造图纸、灵兽精华。空列表 MUST 明确提示为空；装备类条目 MUST 显示稀有度，材料 MUST 显示三性，药材 MUST 显示五行。

#### Scenario: 查看背包汇总

- **WHEN** 玩家发送「背包」
- **THEN** 回复展示未穿戴装备、按类型分组的物品与灵石数量

#### Scenario: 分类查看

- **WHEN** 玩家发送「背包 丹药」
- **THEN** 回复以编号列表展示丹药及数量；无该分类物品时提示列表为空

#### Scenario: 未知分类

- **WHEN** 玩家发送「背包 法宝」
- **THEN** 回复未知分类并列出可选分类

### Requirement: 装备穿戴

系统 MUST 支持「装备 [名称/编号]」穿戴背包中未穿戴的装备。装备有等级要求时，境界不足 MUST 拒绝并说明所需等级；同部位已有装备时 MUST 自动替换并提示被替换装备；名称模糊命中多件时 MUST 列出候选（编号+品质）而不随机选择。穿戴成功后 MUST 显示属性变化。

#### Scenario: 穿戴成功

- **WHEN** 玩家发送「装备 青锋刀」
- **THEN** 装备被穿戴，回复成功信息与力道/攻击等属性变化

#### Scenario: 等级不足

- **WHEN** 玩家境界低于装备等级要求
- **THEN** 回复「等级不足，需要 N 级才能装备 [名称]」，装备保持未穿戴

#### Scenario: 同名多件

- **WHEN** 背包中有多件名称相近的未穿戴装备且输入无法唯一匹配
- **THEN** 回复候选列表，要求玩家用编号精确选择

### Requirement: 装备卸下

系统 MUST 支持「卸下 [部位/名称/编号]」；部位名 MUST 接受 法器/护甲/饰品。该部位未穿戴时 MUST 提示；按名称/编号未找到时 MUST 提示可输入部位名或装备名/编号；成功卸下 MUST 显示属性变化。

#### Scenario: 按部位卸下

- **WHEN** 玩家发送「卸下 法器」
- **THEN** 对应部位装备被卸下，回复装备名与属性变化

#### Scenario: 空部位

- **WHEN** 玩家发送「卸下 护甲」且该部位无装备
- **THEN** 回复该部位未穿戴任何装备，不产生其他副作用

### Requirement: 物品丢弃

系统 MUST 支持「丢弃 [数量] [名称]」丢弃装备或堆叠物品。已装备的装备 MUST 拒绝丢弃并提示先卸下；数量超过持有量时 MUST 按持有量丢弃；未找到物品 MUST 提示。装备丢弃 MUST 删除该实例，堆叠物品 MUST 按数量原子扣减。

#### Scenario: 丢弃堆叠物品

- **WHEN** 玩家发送「丢弃 3 灵芝」且持有 5 个
- **THEN** 灵芝数量减少 3，回复实际丢弃数量

#### Scenario: 丢弃已装备装备

- **WHEN** 玩家尝试丢弃一件已穿戴装备
- **THEN** 回复「[名称]已装备，请先卸下再丢弃」，不删除装备

### Requirement: 装备实例生成

装备获取（掉落/商店/锻造）时，系统 MUST 按模板稀有度掉落权重加权随机稀有度，MUST 在稀有度品质系数区间内随机取值，MUST 按稀有度词条数生成词条（属性词条数值 1~4；传说装可含特殊词条且数值固定）。装备名 MUST 为「模板名-稀有度名」。最终攻击/防御 MUST 随品质系数与锻造等级提升（公式见 design.md）；属性加成 MUST 为模板基础属性与词条加成之和。

#### Scenario: 获得装备

- **WHEN** 玩家通过掉落/购买/锻造获得装备实例
- **THEN** 装备名包含稀有度后缀，详情显示品质系数、攻防与随机词条

#### Scenario: 传说装备词条

- **WHEN** roll 出 LEGENDARY 稀有度
- **THEN** 词条池额外包含吸血/寻宝等特殊词条（数值固定），属性词条数量为 3~4

### Requirement: 装备详情查看

系统 MUST 支持「查看 [装备名/编号]」展示未穿戴装备详情：名称、稀有度与颜色、部位、法器子类型、品质系数、锻造等级、最终攻击/防御、力道/根骨/身法/悟性加成、词条说明。同名多件时 MUST 列出候选要求精确选择。

#### Scenario: 查看装备

- **WHEN** 玩家发送「查看 青锋刀」
- **THEN** 回复展示稀有度、品质系数、攻防、属性加成与词条

### Requirement: 法器克制

玩家装备法器与怪物类型存在克制关系时，玩家造成的伤害 MUST 乘以 1.5；无克制关系时 MUST 为 1.0。克制关系 MUST 为：刀→妖兽、剑→灵体、斧→甲胄、枪→猛兽、棍→邪祟、弓→飞行。系统 MUST NOT 实现被克制方的反向惩罚；灵兽 MUST NOT 参与属性克制。

#### Scenario: 克制命中

- **WHEN** 玩家装备刀与妖兽战斗
- **THEN** 玩家普通攻击与法决伤害均按 1.5 倍结算

#### Scenario: 无克制

- **WHEN** 玩家装备刀与人形怪物战斗
- **THEN** 伤害倍率为 1.0

### Requirement: 堆叠与自动入包

装备 MUST 以独立实例存储且不堆叠；材料/消耗品等堆叠物品 MUST 按「同模板+同属性」合并累加，属性不同 MUST 分行存储。历练结算等玩法掉落物 MUST 自动进入背包，无需手动拾取。

#### Scenario: 同物品合并

- **WHEN** 玩家重复获得同名同属性物品
- **THEN** 背包中该物品数量累加，不产生新行

#### Scenario: 历练掉落

- **WHEN** 历练结算产生掉落物
- **THEN** 掉落物直接进入背包并可在「背包」中查询

### Requirement: 统一物品使用

系统 MUST 提供「使用 [物品名] [参数]」统一入口，按物品类型执行：丹药、法决玉简、丹方卷轴、锻造图纸、灵兽精华。解析 MUST 先精确匹配名称，再模糊匹配；模糊命中多个不同名称时 MUST 要求玩家精确指定，MUST NOT 随机消耗。无可处理类型或未找到物品 MUST 报错。使用成功 MUST 消耗 1 件（玉简在习得成功后消耗；灵兽精华按指定数量消耗）。

#### Scenario: 使用丹药

- **WHEN** 玩家发送「使用 天元丹」
- **THEN** 丹药效果生效并消耗 1 件，回复效果说明

#### Scenario: 模糊重名

- **WHEN** 玩家输入的物品名同时模糊命中多个不同物品
- **THEN** 回复候选名称列表，要求精确指定，不消耗任何物品

#### Scenario: 不可使用物品

- **WHEN** 玩家对无使用处理器的物品类型发送「使用」
- **THEN** 回复「该物品无法使用」，不扣减物品
