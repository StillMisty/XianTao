# Spec Delta

## Purpose

定义丹药 Buff 对玩家可观察的行为契约：服用丹药获得时效增益、战斗增益叠加、突破加成与雷劫抗性、同类堆叠上限、过期与清理、值域约束与提示文案。数据模型、公式与实现细节见同目录 design.md。

## ADDED Requirements

### Requirement: 丹药 Buff 获取

系统 MUST 在玩家服用带 `buff` 类效果的丹药时创建有时效的玩家 Buff。实际增益值 MUST 按「效果基础值 × 成色倍率 × 等级衰减」计算；非雷劫抗性类的实际值 ≤ 0 时 MUST NOT 创建 Buff。持续时间 MUST 由丹药配置的 `duration_seconds` 决定；创建成功后 MUST 回复 Buff 类型、数值与持续秒数。

#### Scenario: 服用增益丹

- **WHEN** 玩家服用带攻击增益效果的丹药
- **THEN** 创建攻击类 Buff，回复「获得 攻击 +N（持续N秒）」，加成在有效期内生效

#### Scenario: 无效增益

- **WHEN** 丹药效果经成色与等级衰减计算后实际值 ≤ 0 且非雷劫抗性
- **THEN** 不创建 Buff，不产生无意义的 0 值记录

### Requirement: 战斗增益生效

有效期内，攻击、防御、速度类 Buff MUST 在构建玩家战斗队伍时按类型分别累加，并 MUST 应用到战斗单位的攻击/防御/速度计算中：

```
玩家攻击 = 有效力道 × 2 + 装备攻击 + 攻击 Buff 总和
玩家防御 = 有效根骨 + 防御 Buff 总和
玩家速度 = 有效身法 × 2 + 10 + 速度 Buff 总和
```

同类型多条 Buff 的数值 MUST 全部累加；已过期的 Buff MUST NOT 参与计算。

#### Scenario: 战斗加成

- **WHEN** 玩家持有未过期的攻击 Buff 参与战斗
- **THEN** 战斗中的玩家攻击力包含该 Buff 的加成总和

#### Scenario: 过期不生效

- **WHEN** 玩家持有的 Buff 已过有效期后进入战斗
- **THEN** 该 Buff 不参与战斗属性计算

### Requirement: 突破加成生效与清除

服用突破类丹药 MUST 写入 1 小时有效的突破成功率加成。执行突破时，系统 MUST 累加所有未过期的突破加成；突破尝试结束后（无论成功或失败）MUST 清除该玩家全部突破类 Buff。

#### Scenario: 突破使用丹药

- **WHEN** 玩家持有未过期的突破加成并执行突破
- **THEN** 本次突破的成功率（或雷劫削弱）包含全部未过期突破加成之和

#### Scenario: 突破后清除

- **WHEN** 一次突破尝试结束，无论成败
- **THEN** 玩家的突破类 Buff 全部被清除，下次突破不再享受旧加成

### Requirement: 雷劫抗性

雷劫抗性类 Buff MUST 在渡劫/大境界突破中削弱雷劫 Boss，削弱比例 = 未过期抗性值之和 ÷ 100，且 MUST 上限为 90%。该类 Buff 的数值 MUST 允许为负（增加雷劫难度），但 MUST NOT 低于 -100。

#### Scenario: 正抗性减伤

- **WHEN** 玩家持有 40% 雷劫抗性 Buff 并触发渡劫
- **THEN** 雷劫 Boss 的难度按 40% 削弱（不超过 90% 上限）

#### Scenario: 负抗性加难

- **WHEN** 玩家服用带负雷劫抗性的丹药（如 -40）
- **THEN** 雷劫难度相应增加，且该负值 Buff 正常创建与过期

### Requirement: 同类堆叠上限

战斗增益与雷劫抗性类 Buff MUST 限制同一类型同时存在的未过期记录数不超过 3 条；达到上限时 MUST 拒绝新增并提示已达堆叠上限，且 MUST NOT 影响已有 Buff。突破加成 MUST NOT 受该上限约束，多颗丹药的加成 MUST 累加。

#### Scenario: 叠满三层

- **WHEN** 玩家已持有 3 条未过期的同类增益 Buff，再服用同类型丹药
- **THEN** 回复已达堆叠上限（3层），不新增 Buff

#### Scenario: 突破加成无上限

- **WHEN** 玩家连续服用两颗突破丹药
- **THEN** 两条突破加成均创建成功，突破时数值累加

### Requirement: 过期与清理

系统 MUST 以 `过期时间 > 当前时间` 作为 Buff 生效条件，过期 Buff MUST NOT 生效；玩家状态结算触发清理时，系统 MUST 删除该玩家的过期 Buff 记录，且 MUST NOT 影响未过期记录。

#### Scenario: 过期即失效

- **WHEN** Buff 超过其过期时间
- **THEN** 战斗、突破与雷劫预报中均不再计入该 Buff

#### Scenario: 懒清理

- **WHEN** 玩家状态结算触发清理
- **THEN** 该玩家的过期 Buff 记录被删除，未过期记录保留

### Requirement: Buff 提示与预报

系统 MUST 在获得 Buff 时回复类型、数值与持续时间；达到堆叠上限时 MUST 回复上限提示；大境界/渡劫的雷劫预报（「状态」面板）MUST 展示已备突破丹药的削劫比例与雷劫抗性百分比。

#### Scenario: 获得提示

- **WHEN** 玩家成功获得一条时效 Buff
- **THEN** 回复包含 Buff 显示名称、实际数值与持续秒数

#### Scenario: 预报展示

- **WHEN** 处于大境界/渡劫门槛的玩家查看「状态」且持有突破加成或雷劫抗性 Buff
- **THEN** 雷劫预报展示「丹药已备（削劫X%）」与「雷抗加身（抗雷X%）」
