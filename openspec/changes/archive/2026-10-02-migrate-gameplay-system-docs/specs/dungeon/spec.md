# Spec Delta

## Purpose

定义秘境系统对玩家可观察的行为契约：秘境列表与准入条件、进入与实例互斥、进度查看、秘灵自然语言对话、区域探索与 POI 结算、区域推进与通关、通关奖励与每日上限、撤退，以及秘境之灵好感度与隐藏内容发现。秘境数据模型、工具集与数值细节见同目录 design.md。

## ADDED Requirements

### Requirement: 秘境列表与可见性

系统 MUST 支持「秘境」指令展示全部已开放秘境：名称、五行属性、境界范围、队伍上限、当日奖励进度与首通标记、入口所在位置。不可进入的秘境 MUST NOT 从列表中隐藏，MUST 展示不可进入原因。

#### Scenario: 查看秘境列表

- **WHEN** 玩家处于空闲状态并发送「秘境」
- **THEN** 列出所有开放秘境及其境界、队伍上限、奖励进度与入口位置

#### Scenario: 展示不可进入原因

- **WHEN** 玩家境界或位置不满足某秘境准入条件
- **THEN** 该秘境仍出现在列表中，并标注「暂不可入」及原因

### Requirement: 秘境准入条件

进入秘境前系统 MUST 校验模板配置的全部准入条件：位置条件（玩家必须在指定地图节点）、境界条件（等级范围）、道具条件（背包持有指定物品）、前置通关条件（已首通指定秘境）、隐藏完成条件（已完成指定隐藏事件）。任一条件不满足时 MUST 拒绝进入并说明原因；无配置条件时 MUST 不限制。

#### Scenario: 境界不足

- **WHEN** 玩家等级低于秘境最低境界要求并尝试进入
- **THEN** 拒绝进入并提示所需境界范围

#### Scenario: 不在入口位置

- **WHEN** 玩家不在秘境入口地图节点并尝试进入
- **THEN** 拒绝进入并提示当前不在秘境所在位置

#### Scenario: 无准入限制

- **WHEN** 秘境未配置任何准入条件
- **THEN** 玩家可直接进入

### Requirement: 进入秘境与实例互斥

系统 MUST 支持「秘境 名」快捷进入。进入时玩家 MUST 处于空闲状态，否则 MUST 拒绝并提示当前状态。同一玩家在同一秘境 MUST 最多存在一个进行中的实例：已有未过期实例时 MUST 拒绝重复进入；已有实例已超时 MUST 先将其关闭并允许重新进入。进入成功后 MUST 返回首区域名与描述：有秘境之灵时附带形象与问候，无秘境之灵时列出可探索地点并引导「秘灵 内容」。

#### Scenario: 进入成功

- **WHEN** 空闲玩家满足准入条件并发送「秘境 秘境名」
- **THEN** 创建进行中实例，回复首区域开场叙事并进入秘境状态

#### Scenario: 重复进入

- **WHEN** 玩家已在该秘境中再次尝试进入
- **THEN** 拒绝进入并提示已在秘境中

#### Scenario: 实例超时后重进

- **WHEN** 玩家的旧实例已超过秘境时限
- **THEN** 系统先关闭旧实例，再允许玩家重新进入

### Requirement: 秘境进度查看

玩家在秘境中发送「秘境」时，系统 MUST 展示静态进度概览：当前区域名、已探索地点数 / 主线地点总数、已用时长，且 MUST NOT 调用 LLM。不在秘境中时「秘境」MUST 回退为秘境列表。

#### Scenario: 查看进度

- **WHEN** 秘境中的玩家发送「秘境」
- **THEN** 回复「区域名 | 探索 x/y | 用时 Nmin」并引导继续用「秘灵 内容」探索

#### Scenario: 不在秘境中

- **WHEN** 不在秘境中的玩家发送「秘境」
- **THEN** 展示秘境列表而非进度

### Requirement: 秘灵对话与叙事

系统 MUST 支持「秘灵 内容」与秘境之灵 / 叙事者自然语言对话：由 LLM 根据当前区域、已探索地点、好感度与隐藏线索进行叙事，并按其判断调用探索、推进、撤退、好感等操作。不在秘境中时 MUST 拒绝对话；「秘灵」无内容时 MUST 返回用法引导；AI 不可用时 MUST 返回可读降级文案且不影响后续指令。

#### Scenario: 对话驱动探索

- **WHEN** 秘境中玩家发送「秘灵 我过去看看那块石碑」
- **THEN** 秘灵以叙事回应并按需结算对应地点的探索

#### Scenario: 不在秘境中

- **WHEN** 不在秘境中的玩家发送「秘灵 你好」
- **THEN** 拒绝并提示当前不在任何秘境中

#### Scenario: 无内容引导

- **WHEN** 玩家只发送「秘灵」
- **THEN** 回复「秘灵 你说的话」用法与示例

### Requirement: 区域探索与 POI 结算

系统 MUST 按区域配置结算地点探索：地点 MUST 属于当前区域、MUST 未被探索过、MUST NOT 为通道类型（通道在主线全清后自动激活）。战斗地点 MUST 从怪物池按权重抽取并即时完成战斗，胜利后 MUST 掉落战利品并给出战斗摘要；失败 MUST 不给予战利品，队伍被全歼时玩家 MUST 进入濒死。采集与搜索地点 MUST 掉落战利品，搜索 MUST 有概率遭遇战斗。隐藏地点 MUST 可被探索并按名结算，发现后 MUST 记录。已探索地点重复探索 MUST 被拒绝。

#### Scenario: 战斗地点胜利

- **WHEN** 玩家通过秘灵探索当前区域的战斗地点并获胜
- **THEN** 获得战利品与战斗摘要，该地点标记为已探索

#### Scenario: 战斗失败

- **WHEN** 探索战斗地点但队伍被击败
- **THEN** 不获得战利品，队伍被全歼时玩家进入濒死状态

#### Scenario: 重复探索

- **WHEN** 玩家再次探索已探索过的地点
- **THEN** 提示该地点已经探索过，不重复结算

### Requirement: 区域推进与通关

当前区域除通道外的全部主线地点探索完毕后，系统 MUST 解锁通往下一区域的通道；通道未解锁时推进 MUST 被拒绝。玩家通过秘灵推进后 MUST 进入下一区域，上一区域 MUST 关闭且不可返回。已在最后一个区域时推进 MUST 触发通关结算。

#### Scenario: 推进到下一区域

- **WHEN** 当前区域主线地点全部探索完毕且玩家要求继续深入
- **THEN** 通道解锁并推进到下一区域，返回新区域描述与可探索地点

#### Scenario: 通道未解锁

- **WHEN** 主线地点尚未探索完时玩家要求推进
- **THEN** 拒绝推进并提示先探索完当前区域

#### Scenario: 通关

- **WHEN** 玩家在最后一个区域完成全部主线探索后推进
- **THEN** 触发通关结算并离开秘境

### Requirement: 通关奖励与每日上限

通关时系统 MUST 发放灵石奖励，并受每日奖励次数上限约束：达到上限时 MUST 不发放奖励并明确提示。系统 MUST 记录首通标记；每日上限 MUST 按玩家等级计算，等级越高上限越高。

#### Scenario: 首次通关

- **WHEN** 玩家首次通关某秘境且当日奖励次数未达上限
- **THEN** 发放灵石奖励并标记首次通关

#### Scenario: 达到每日上限

- **WHEN** 玩家当日通关奖励次数已达上限后再次通关
- **THEN** 不发放灵石并提示今日奖励次数已达上限

### Requirement: 撤退

系统 MUST 支持玩家通过秘灵撤退离开秘境；撤退后实例 MUST 结束、玩家 MUST 恢复空闲状态，已获得的奖励 MUST 保留。

#### Scenario: 撤退离开

- **WHEN** 玩家在秘境中要求离开
- **THEN** 结束当前实例并回到空闲状态，已获物品与灵石不受影响

### Requirement: 好感度、线索与隐藏内容

开启好感系统的秘境 MUST 维护秘境之灵好感度与态度分档，并允许秘灵按玩家言行调整好感；好感度 MUST 影响提示主动性，好感高时秘灵 MUST 更主动地暗示隐藏内容。好感度 ≥20 时玩家 MUST 可消耗好感度向秘灵换取一条当前区域未发现隐藏地点的线索，无可用线索时 MUST 拒绝且不扣好感。有线索配置的隐藏地点 MUST 由秘灵在叙事中自然暗示；未配置线索的隐藏地点 MUST NOT 被主动提及，只能由玩家自主探索发现。

#### Scenario: 消耗好感换线索

- **WHEN** 好感度不低于 20 且当前区域存在未发现的隐藏地点
- **THEN** 扣除 20~30 好感度并返回一条隐藏线索

#### Scenario: 好感不足

- **WHEN** 好感度低于 20 时请求线索
- **THEN** 拒绝并提示好感度不足，不扣好感

#### Scenario: 已发现的隐藏地点

- **WHEN** 某隐藏地点已被探索发现
- **THEN** 秘灵不再对该地点进行线索暗示
