# Spec Delta

## Purpose

定义炼丹系统对玩家可观察的行为契约：丹方学习与查询、自动与手动炼丹、五行匹配与成色判定、丹药服用效果、等级衰减与抗性衰减、以及未学卷轴等引导提示。公式、数据模型与实现细节见同目录 design.md。

## ADDED Requirements

### Requirement: 丹方学习

系统 MUST 支持通过「使用 [丹方卷轴名]」学习丹方。卷轴类型 MUST 为丹方卷轴；同一丹方 MUST NOT 重复学习，重复时拒绝并提示已学会；非丹方卷轴物品 MUST 拒绝并提示类型错误。学习成功后 MUST 消耗 1 件卷轴并回复所学丹方名称。

#### Scenario: 学习丹方

- **WHEN** 玩家背包中有「小聚灵丹方」并发送「使用 小聚灵丹方」
- **THEN** 学会该丹方，消耗 1 件卷轴，回复学习成功与丹方名称

#### Scenario: 重复学习

- **WHEN** 玩家已学会某丹方后再次使用同名卷轴
- **THEN** 拒绝学习并提示已学会该丹方

### Requirement: 丹方列表与详情

系统 MUST 支持「丹方」查看已学丹方列表（编号、名称、品阶），空列表 MUST 提示尚未学会任何丹方；MUST 支持「丹方 [名称]」按名称模糊匹配查看详情，展示品阶、成品名称与数量、各五行要求的区间。未匹配到已学丹方时 MUST 报「未找到丹方」。

#### Scenario: 查看列表

- **WHEN** 玩家已学会至少一个丹方并发送「丹方」
- **THEN** 回复编号列表，每项含丹方名称与品阶，并提示查看详情的方式

#### Scenario: 查看详情

- **WHEN** 玩家发送「丹方 聚灵」
- **THEN** 回复匹配丹方的品阶、成品与五行要求区间

#### Scenario: 未找到

- **WHEN** 玩家发送「丹方 不存在的丹方」
- **THEN** 回复未找到丹方，不产生其他副作用

### Requirement: 自动炼丹

系统 MUST 支持「炼方 [丹方名]」自动炼丹：按名称匹配已学丹方，从背包自动挑选最多 5 种药材并计算份数，使累计五行落在丹方要求区间内；无可用药材 MUST 提示背包中没有药材；任一属性不足 MUST 提示缺少的五行（中文名）且不消耗药材；任一属性超过上限 MUST 提示超限属性且不消耗药材。成丹后 MUST 按实际用量扣减药材并产出对应成色的丹药。

#### Scenario: 自动成丹

- **WHEN** 玩家已学目标丹方且背包药材足以满足全部五行要求
- **THEN** 系统选出药材组合，扣减药材并产出丹药，回复成丹名称、数量与成色

#### Scenario: 属性不足

- **WHEN** 背包药材无法满足丹方某一五行要求
- **THEN** 回复缺少的五行名称，不消耗任何药材

#### Scenario: 未学卷轴引导

- **WHEN** 玩家发送「炼方 [名称]」但只持有同名丹方卷轴、尚未学习
- **THEN** 回复提示背包中有同名卷轴，请先「使用 [卷轴名]」学习

### Requirement: 手动炼丹

系统 MUST 支持「炼 [药材名数量 ...]」手动炼丹，输入格式为「名称紧连正整数数量」（如 `灵草3`），最多 5 段；全部输入无效时 MUST 提示格式示例。系统 MUST 用指定药材的五行累计匹配已学丹方；命中时 MUST 按指定数量扣减药材并产出丹药；无任何丹方匹配 MUST 报「药材五行不匹配任何丹方」且不消耗药材；指定数量超过持有量时 MUST 报数量不足并整体回滚。

#### Scenario: 手动成丹

- **WHEN** 玩家发送「炼 灵芝3 血参2」且累计五行命中某个已学丹方
- **THEN** 按输入扣减对应药材并产出丹药，回复成色与消耗明细

#### Scenario: 无匹配丹方

- **WHEN** 玩家指定药材的五行累计不落在任何已学丹方的区间内
- **THEN** 回复药材五行不匹配任何丹方，不消耗药材

#### Scenario: 数量不足

- **WHEN** 玩家指定「灵芝99」但背包持有量不足
- **THEN** 回复物品数量不足，炼丹失败且不产出丹药

### Requirement: 成丹与成色判定

系统 MUST 以「实际五行值相对要求区间中心的接近度」计算每项达标度（区间中点为 1，越偏离越低，低于下限记 0），并取所有涉及属性的平均值判定成色：≥ 0.8 上成（效果 ×1.5）、≥ 0.5 中成（×1.0）、否则下成（×0.7）。丹方不涉及的属性 MUST NOT 参与成色计算。产出丹药 MUST 记录品阶与成色，同模板同属性的丹药 MUST 合并堆叠。

#### Scenario: 上成产出

- **WHEN** 药材组合的各属性均接近区间中心，平均达标度 ≥ 0.8
- **THEN** 产出上成丹药，效果倍率按 ×1.5 记录

#### Scenario: 边缘命中

- **WHEN** 各属性恰好等于区间下限、平均达标度为 0
- **THEN** 产出下成丹药，效果倍率按 ×0.7 记录

### Requirement: 丹药服用效果

系统 MUST 支持「使用 [丹药名]」服用丹药，消耗 1 件后依次应用模板效果列表：增加修为、回复气血（固定值或最大气血百分比）、永久增加四维之一、写入突破成功率加成、写入时效增益、驱散/复活。玩家处于濒死状态时，服用气血类或驱散类丹药 MUST 复活并回满气血。实际数值 MUST 按「效果基础值 × 成色倍率 × 等级衰减 × 抗性衰减」计算（仅修为与属性受抗性影响）；实际值 ≤ 0 的效果 MUST NOT 生效。

#### Scenario: 服用修为丹

- **WHEN** 玩家服用带修为效果的丹药
- **THEN** 修为按基础值 × 成色 × 衰减增加，回复增加量

#### Scenario: 濒死复活

- **WHEN** 濒死状态玩家服用带气血效果的丹药
- **THEN** 气血回满、状态恢复为空闲，回复复活提示

#### Scenario: 多效果丹药

- **WHEN** 玩家服用同时含修为与回血效果的丹药
- **THEN** 两类效果均生效，回复合并后的效果文案

### Requirement: 等级衰减

修为、属性、突破加成与增益效果 MUST 受品阶/等级衰减影响：衰减系数 = `min(1, 品阶 / (玩家等级 × 0.2))`，且实际实现 MUST 对修为、属性、突破、增益统一应用 0.1 保底。品阶 MUST 由丹药自身数据决定，低品丹药对高等级玩家的效果 MUST 显著下降。

#### Scenario: 低品丹药高等级

- **WHEN** 高等级玩家服用低品丹药
- **THEN** 效果按衰减系数缩减，回复中体现实际生效数值

### Requirement: 抗性衰减

修为与属性类效果 MUST 累积抗性：按「丹药模板 + 成色」独立计数，每次实际生效后计数 +1；抗性衰减 = `max(0.1, 1 / (1 + 计数 × 0.3))`，且 MUST NOT 随时间自动衰减。气血、突破与增益类效果 MUST NOT 增加抗性计数。

#### Scenario: 连续服用同一丹药

- **WHEN** 玩家重复服用同一模板同成色的修为丹
- **THEN** 每次效果按当前抗性计数递减，最低不低于基础值的 0.1

#### Scenario: 不同成色独立计数

- **WHEN** 玩家交替服用同一模板的上成与下成丹药
- **THEN** 两种成色的抗性计数分别累计，互不影响
