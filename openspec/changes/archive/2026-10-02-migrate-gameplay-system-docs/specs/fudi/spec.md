# Spec Delta

## Purpose

定义福地系统对玩家可观察的行为契约：福地创建与状态查询、地块布局与扩建、建造拆除与升级、灵田种植与收获、地灵自然语言经营入口、地灵好感与送礼，以及天劫的触发、冷却与胜负结算。地块数据模型、公式与灵石数值见同目录 design.md，灵兽侧规则见 `beasts` 规格。

## ADDED Requirements

### Requirement: 福地创建与状态查询

玩家注册成功后 MUST 自动获得福地，初始包含 3 块空地，并绑定一名随机形态、随机 MBTI 人格的地灵。系统 MUST 支持「福地」指令展示福地概况：劫数、连胜、地灵形态、地灵人格、已占地块数与总地块数。地灵人格 MUST 锁定不可更改。

#### Scenario: 注册后查询福地

- **WHEN** 新注册玩家发送「福地」
- **THEN** 展示初始 3 块地块、当前劫数与连胜，以及地灵形态与人格

#### Scenario: 地灵信息可见

- **WHEN** 玩家发送「福地」
- **THEN** 回复包含地灵形态名与 MBTI 人格代号

### Requirement: 福地地块布局

系统 MUST 支持「福地地块」指令展示全部地块：每块地 MUST 显示编号与类型（空地 / 灵田 / 兽栏）；灵田 MUST 显示作物名与生长进度（成熟时标注可收取）；兽栏 MUST 显示灵兽名、品质、等阶、变异特质、暂存产出与孵化中状态（无内容时显示空地或空兽栏）。

#### Scenario: 灵田成熟可见

- **WHEN** 玩家查看福地地块且某灵田已成熟
- **THEN** 该地块显示作物名、100% 进度与「可收取」标记

#### Scenario: 兽栏信息

- **WHEN** 玩家查看福地地块且兽栏内有灵兽
- **THEN** 该地块显示灵兽名、品质、等阶与特质（若有）、暂存产出（若有）

### Requirement: 地块扩建

福地地块 MUST 随劫数自动扩建：`地块总数 = 3 + floor(劫数 / 3)`，扩建无消耗。系统 MUST 在玩家查询「福地」或「福地地块」时懒加载补齐应开放但尚未创建的地块。

#### Scenario: 初始地块

- **WHEN** 玩家注册后首次查看福地
- **THEN** 福地有 3 块空地

#### Scenario: 劫数达标后扩建

- **WHEN** 玩家劫数达到 3 后查询「福地」或「福地地块」
- **THEN** 第 4 块空地自动开放并出现在布局中

### Requirement: 地块建造与拆除

系统 MUST 支持玩家通过地灵对话在空地建造灵田或兽栏：建造灵田 MUST 消耗 50 灵石，建造兽栏 MUST 消耗 100 灵石；目标地块 MUST 为空地且编号在已开放范围内；灵石不足或地块已被占用时 MUST 拒绝且不扣费。拆除 MUST 将地块返还为空地、不返还灵石，并解除兽栏中灵兽的占用。

#### Scenario: 建造灵田

- **WHEN** 玩家通过地灵对话在空地建造灵田且灵石充足
- **THEN** 扣除 50 灵石，该地块变为灵田（Lv1）

#### Scenario: 地块已被占用

- **WHEN** 玩家在已有建筑的地块上建造
- **THEN** 回复该地块已被占用，不扣除灵石

#### Scenario: 拆除地块

- **WHEN** 玩家通过地灵对话拆除已有建筑的地块
- **THEN** 地块返还为空地，不返还建造费用

### Requirement: 地块升级

系统 MUST 支持通过地灵对话升级灵田 / 兽栏：Lv1→Lv2、Lv2→Lv3、Lv3→Lv4、Lv4→Lv5 分别消耗 200 / 400 / 800 / 1600 灵石；Lv5 MUST 为上限；空地 MUST NOT 被升级；灵石不足时 MUST 拒绝。升级 MUST 提高生长加速系数（基准为作物等阶）。

#### Scenario: 升级地块

- **WHEN** 玩家对 Lv2 地块执行升级且灵石充足
- **THEN** 扣除 400 灵石，地块变为 Lv3

#### Scenario: 已达上限

- **WHEN** 玩家对 Lv5 地块执行升级
- **THEN** 回复已是最高阶，不扣灵石

#### Scenario: 灵石不足

- **WHEN** 玩家升级地块但灵石不足
- **THEN** 回复灵石不足及所需数量，地块等级不变

### Requirement: 灵田种植

系统 MUST 支持通过地灵对话播种：目标地块 MUST 为空地或灵田，玩家背包 MUST 持有对应种子，播种 MUST 消耗 1 颗种子。作物 MUST 有等阶（由基础生长时间推导），等阶 MUST NOT 超过灵田等级，否则 MUST 拒绝。生长时间 MUST 为基础生长时间除以等级加速系数（下限 0.1 小时），成熟后 MUST 可收获。

#### Scenario: 播种成功

- **WHEN** 玩家通过地灵对话在空灵田播种背包中的种子
- **THEN** 消耗 1 颗种子，地块记录种植时间与成熟时间，并回复基础生长时间

#### Scenario: 灵田等阶不足

- **WHEN** 玩家播种的作物等阶高于灵田等级
- **THEN** 回复需要更高阶灵田，不消耗种子

#### Scenario: 种子不足

- **WHEN** 玩家播种背包中没有的种子
- **THEN** 回复背包中没有该种子，不改变地块

### Requirement: 灵田收获

系统 MUST 支持通过地灵对话收获成熟灵田（单个地块或批量全部）：未成熟时 MUST 拒绝；收获 MUST 按模板产量随机产出物品（缺省 1~3 件，含变异判定）。多季作物收获后 MUST 重置生长进度并可继续收获至次数上限；单季作物收获后地块 MUST 返还为空地。枯萎作物（成熟后超过 2 倍基础生长时间未收）在收取时 MUST 被清除并提示枯萎。

#### Scenario: 收获成熟作物

- **WHEN** 玩家通过地灵对话收获成熟灵田
- **THEN** 产出物品进入背包并回复收获数量

#### Scenario: 尚未成熟

- **WHEN** 玩家收获未成熟的灵田
- **THEN** 回复灵药尚未成熟，不产出物品

#### Scenario: 枯萎

- **WHEN** 玩家收获已枯萎的单季灵田
- **THEN** 提示作物已枯萎并清除该地块，不产出物品

### Requirement: 地灵对话与经营入口

系统 MUST 以「地灵 内容」自然语言对话作为福地经营入口：种植、收取、建造、拆除、升级、灵兽操作与送礼 MUST 通过对话完成，系统 MUST NOT 提供对应的固定指令。AI 服务不可用时 MUST 返回可读的降级提示，且 MUST NOT 影响玩家后续指令。

#### Scenario: 自然语言经营

- **WHEN** 玩家发送「地灵 帮我在 2 号地种下灵芝」
- **THEN** 地灵按对话内容执行播种并回复结果

#### Scenario: AI 不可用

- **WHEN** AI 服务暂不可用
- **THEN** 回复「地灵暂时无法回应」等降级文案，玩家可稍后重试

### Requirement: 地灵好感与送礼

地灵好感 MUST 在 0~1000 范围内。系统 MUST 支持通过地灵对话送礼，每日限一次；礼物按物品标签与地灵形态的喜好 / 讨厌标签判定：命中喜好 MUST 增加好感（+10~+50），命中讨厌 MUST 降低好感（-5~-20），均未命中 MUST 小幅增加（+1~+3）；礼物 MUST 被消耗。地灵对玩家冒犯言行的不满 MUST 降低好感（-1~-5）。

#### Scenario: 送出喜欢的礼物

- **WHEN** 玩家赠送地灵形态喜欢的物品且当日未送过礼
- **THEN** 好感上升并回复「开心」反应，物品被消耗

#### Scenario: 当日已送礼

- **WHEN** 玩家在同一天第二次送礼
- **THEN** 回复今日已送过礼物，不消耗物品、不改变好感

#### Scenario: 冒犯地灵

- **WHEN** 玩家在地灵对话中有冒犯言行
- **THEN** 地灵表达不满并按程度降低好感

### Requirement: 天劫触发

系统 MUST 支持玩家通过「福地渡劫」指令或地灵对话主动引动天劫。天劫 MUST 有 1 小时冷却：冷却中 MUST 拒绝并提示剩余时间。防守方 MUST 由玩家与出战灵兽组成，无存活单位时 MUST 拒绝。天劫化身属性 MUST 随劫数缩放，战斗 MUST 为最多 40 回合的回合制。

#### Scenario: 正常触发

- **WHEN** 玩家在天劫冷却结束后引动天劫且有可出战单位
- **THEN** 进入天劫战斗并返回战斗结果与当前劫数、连胜

#### Scenario: 冷却中

- **WHEN** 距上次天劫不足 1 小时时再次引动
- **THEN** 回复天劫刚过、需等待剩余小时数，不进入战斗

#### Scenario: 无出战单位

- **WHEN** 玩家没有可出战的单位时引动天劫
- **THEN** 回复没有可出战的单位，天劫无法降临

### Requirement: 天劫结算

天劫战斗结束后 MUST 按结果结算：**胜利**（击退天劫化身）劫数 +1、连胜 +1、灵石奖励 = 新连胜 × 100、地灵好感 +5；**怜悯庇护**（战败且地灵好感 ≥800）劫数 +1、连胜 +1、灵石奖励 = 新连胜 × 100、好感不变；**失败**（战败且好感 <800）连胜清零、按天劫化身剩余气血比例摧毁已占用地块（剩余 ≥50% 摧毁 60%、20%~50% 摧毁 30%、<20% 摧毁 1 块）、好感按被毁地块数下降。

#### Scenario: 胜利

- **WHEN** 防守方击退天劫化身
- **THEN** 劫数与连胜各 +1，获得连胜 ×100 灵石，地灵好感 +5

#### Scenario: 怜悯庇护

- **WHEN** 防守方战败但地灵好感不低于 800
- **THEN** 劫数与连胜各 +1，获得灵石奖励，地灵好感不变

#### Scenario: 战败摧毁地块

- **WHEN** 防守方战败且地灵好感低于 800
- **THEN** 连胜清零，按天劫化身剩余气血比例摧毁若干已占用地块，地灵好感下降
