一、测试方法

用 tools/e2e/playtest.py 在独立测试库上模拟真实玩家，逐条发送指令并记录 完整回复、延迟、字数、按钮。五个阶段：

  • 新手旅程（28 步）：未注册 → 注册 → 帮助 → 地图 → 旅行 → 历练 → 悬赏 → 突破……第一小时体验；
  • 易用性负路径（15 步）：缺参、错别字、重复注册、非命令消息、越权；
  • 中期深挖（55 步）：造数据（10/21 级、修为、灵石、药材/卷轴/图纸/玉简/兽卵/装备）后逐系统走通；
  • 双人社交（13 步）：拜师/收徒/护道/切磋/逐出/叛师；
  • 补齐深挖（24 步）：早期突破、秘境入口、有境界差的师徒、可参与的世界事件。

造数据手段：GM 指令（等级/修为/灵石/物品）+ 测试库 SQL 时间回拨（player.activity_start_time、user_bounty.start_time），跳过 15–40 分钟的时间墙。不触碰真实 QQ 与开发库。

四、发现清单（原始记录）

P0 阻塞

秘境列表永远不可见，核心 PvE 系统实际不可达

现象
不在秘境中时输入「秘境」，永远返回状态文案而不是可进入的秘境列表；文案还自相矛盾地提示「输入「秘境」查看可进入的秘境」。
证据
秘境（新手/中期/深挖三轮均如此）： ### 秘境进度 你当前不在任何秘境中。输入「秘境」查看可进入的秘境。 > 💡 输入「秘灵 内容」与秘境之灵/叙事者对话
代码定位
DungeonService.statusInDungeon 恒返回 Success(getStatusInternal())；DungeonCommandHandler.handleDungeonOrStatus 只认 Success 分支 → formatDungeonList 是死代码。
影响
玩家无法发现秘境名称、入口位置与等级门槛（实测「紫府秘境」需站在同名节点、5–30 级）。这是游戏主要的组队 PvE 内容，却只能靠外部信息进入。
建议
未在秘境中时返回 Failure（或 handler 先判断状态）走 listDungeons；列表中标注入口地图与等级区间。
高

英文内部键泄漏（一）：世界事件奖励文案

证据
参与事件（深挖阶段）： 你参与了**悬赏缉凶**！ 获得修为 +2000，spiritStones: +80
代码定位
WorldEventParticipationService.buildEffectDescription 只匹配 spirit_stone（下划线）；camelCase 键 spiritStones（来自 AddSpiritStonesEffect.description()）落入 else 分支被原样输出。
建议
键名归一化后匹配（小写、去下划线），如 spirit+stone 判定灵石；并补一个「未识别键不展示」的兜底。
高

英文内部键泄漏（二）：炼丹五行属性报错

证据
炼方（中期深挖）： ❌ 缺少药材属性：metal
代码定位
CombinationStrategy.collectMissingAttributes 返回丹方 requirements 的原始键（metal/wood/water/fire/earth），ErrorCode.PILL_ELEMENT_MISSING 直接拼接；锻造的 ForgingCombinationFinder 同源。代码库中没有 element → 中文映射。
影响
玩家看不懂英文属性名，也无法从报错得知「当前药材有什么、还差什么」，五行炼丹的门槛被人为抬高。
建议
增加元素中文映射（金/木/水/火/土）；报错同时给出当前药材属性汇总与建议配方。
高

缺参命令完全静默

证据
负路径阶段（每条等待 10 秒，无任何回复）： 「前往」 → <无回复> 「装备」 → <无回复> 「回收」 → <无回复> 「使用」 → <无回复>
影响
「命令打一半」是新手最常见的操作；零反馈会让玩家以为机器人掉线。同类静默还有非命令闲聊（可接受，但新手期可给一次帮助提示）。
建议
为高频命令补裸命令兜底（@Command("前往") → 用法与示例），或在调度层对「前缀唯一命中但缺参」统一回复用法提示。
高

强化重名装备报「未找到该装备」

证据
中期深挖（背包中有两把「砍柴刀」时）： 强化 砍柴刀 → 未找到该装备 （首次运行时只有一把，强化成功：「砍柴刀-破旧 → +1，消耗灵石 32」）
代码定位
EnhancementCore.resolveEquipment 把 ItemResolver 的「多匹配」与「未找到」都折叠为 null → 统一抛 EQUIPMENT_NOT_FOUND；而背包/使用等系统在重名时会用 ITEM_MULTIPLE_MATCH（「找到多个…」）。
建议
区分多匹配与未找到，输出候选（品质/强化等级/编号），与其余系统文案一致。
中

卷轴/图纸学习引导缺失：直接「炼方/锻造」只会说未找到

证据
首轮（卷轴/图纸就在背包里）： 炼方 小聚灵丹方 → ❌ 未找到丹方：小聚灵丹方 锻造 砍柴刀图 → 未找到名为「砍柴刀图」的锻造图纸 正确姿势（第二轮验证）： 使用 小聚灵丹方 → 学习丹方成功：小聚灵丹方 使用 砍柴刀图 → 学习锻造图纸成功：砍柴刀图
建议
报错时检索背包中的同名卷轴/图纸，提示「请先使用「X」学习」；或让「炼方/锻造」自动尝试先学习。
中

历练结算没有收益数字，文案与实际状态矛盾

证据
90 分钟历练结算（无遭遇战）： ### 历练结算 翠竹林 | 1小时30分钟 | 效率1.0x ### 历练收获 你在翠竹林已修炼 90 分钟，继续精进中。 追加通知：你在翠竹林历练了 90 分钟，有所收获。
影响
没有遭遇战就没有修为（0 收益），但文案说「有所收获」；「继续精进中」与实际结算后状态不一致；玩家无从判断这次历练值不值。
建议
结算列出本次收益明细（修为/掉落/遭遇次数）；无收益时如实说明；「继续精进中」仅在真的继续时使用。

五、可玩性观察

✓ 做得好的

  • 新手引导链顺畅：注册 → 状态 → 背包（提示装备桃木剑）→ 地图 → 前往 → 历练，关键节点都有下一步提示。
  • 位置门槛有解释：「青石镇人烟稠密，不宜吐纳。可先「前往 翠竹林」（其妖兽多为炼气期 · 启灵修为），抵达后再行修炼。」——原因 + 目的地 + 预期收益俱全。
  • AI NPC 在线：地灵会调用工具种田（3.6s 完成播种）、掌柜能报价成交、秘灵会引导探索分支、宗灵有守山人设；语气贴合世界观。
  • 秘境入口叙事：「你踏入了【紫府秘境】—外围，灵雾缭绕的山门区域…」进入感强。
  • 师徒/护道闭环完整：拜师自动建护道、面板清晰、24h 冷却提示明确、切磋可用（有完整战斗记录）。
  • 早期突破正反馈明确：100% 成功率、文案+境界变化即时可见。
  • 地图按钮已验证：回复附带「翠竹林」按钮，点击即发送「前往 翠竹林」。

⚠ 风险与节奏

  • 时间墙偏长：悬赏 15–40 分钟、历练按小时结算；符合 AFK 定位，但缺少「完成提醒」，玩家需要自己记得回来结算（平台主动推送能力已下线，无法做完成提醒）。
  • 突破难度：10 级突破连续两次被雷劫击败（残血 7%），失败清空所需修为并清除护道；需要评估失败补偿曲线与挫败感。
  • 福地渡劫可误触：开局即可挑战，失败毁 1 块地块（实测把刚种下的种子一起毁了），没有二次确认或门槛提示。
  • 五行炼丹门槛高：单味药材报「不匹配」，报错又不给配比方向（见 P1-2）。
  • 两套「雷劫」容易混淆：境界突破雷劫 vs 福地渡劫，命名与入口都叫「渡劫/天劫」。
  • 经济循环基本可用：锻造消耗锻材、强化消耗灵石（32/次）、掌柜买卖可用；但买卖全部依赖 AI 对话，无确定性命令兜底（AI 故障时商铺不可用）。
