# Spec Delta

## Purpose

定义通用战斗引擎的行为契约：懒结算模拟、行动顺序与技能选择、技能效果与 Buff/Debuff、受击反应、伤害与法器克制、玩家战斗属性构成（含装备与 Buff）、玩家/灵兽参战、怪物缩放与掉落、动态遇怪、高光战斗与战后结算。具体公式与实现细节见同目录 design.md。

## ADDED Requirements

### Requirement: 玩家战斗属性构成

玩家战斗单位的攻击、防御与速度 MUST 由有效四维、已穿戴装备加成与生效 Buff 共同构成：

```
玩家攻击 = (有效力道 + 装备力道) × 2 + 装备总攻击 + 攻击 Buff 总和
玩家防御 = (有效根骨 + 装备根骨) + 装备总防御 + 防御 Buff 总和
玩家速度 = (有效身法 + 装备身法) × 2 + 10 + 速度 Buff 总和
```

装备加成 MUST 取自已穿戴装备的最终值（含品质波动、随机词条与锻造强化），且 MUST 与「状态」「查看」展示共用同一聚合口径。

#### Scenario: 装备参与战斗

- **WHEN** 玩家穿戴提供四维与攻击/防御加成的装备参战
- **THEN** 其战斗攻击/防御按上式计入装备四维与装备总攻/总防，高于卸下装备时

#### Scenario: 装备口径一致

- **WHEN** 玩家更换为属性更高的装备
- **THEN** 「状态」展示与战斗计算按同一装备聚合同步变化，不出现两处数值口径不一致
