# Spec Delta

## Purpose

定义境界突破的分流规则与雷劫战斗契约：小境界走概率骰子，跨大境界与渡劫期走雷劫战斗；涵盖雷劫类型解锁、Boss 缩放与削弱、突破消耗与失败保底、雷劫抗性丹药、战胜/战败结算、招雷散渡劫补偿与战后气血写回、雷劫预报与战斗叙事。数值公式与实现细节见同目录 design.md。

## ADDED Requirements

### Requirement: 渡劫战后气血写回

渡劫战斗结束后 MUST 将玩家与灵兽的气血写回：玩家战胜时 MUST 回满气血；玩家战败（含超时未胜）时 MUST 按战斗剩余气血写回，气血归零 MUST 进入濒死。灵兽无论胜败 MUST 按战斗剩余气血写回；战斗中气血归零的灵兽 MUST 取消出战并按品质进入休养期。

#### Scenario: 战败残血或濒死

- **WHEN** 玩家在渡劫战斗中落败
- **THEN** 玩家按战斗剩余气血写回；气血归零时进入濒死

#### Scenario: 灵兽带伤或休养

- **WHEN** 渡劫战斗结束且出战灵兽受伤或阵亡
- **THEN** 存活者按战斗剩余气血带伤写回，阵亡者取消出战并进入按品质计时的休养

## MODIFIED Requirements

### Requirement: 战胜奖励

雷劫战胜 MUST 提升等级、失败计数归零、玩家气血回满。跨大境界成功 MUST 额外获得有效四维 +20% 与灵石奖励；渡劫期层级提升 MUST 获得有效四维 +5%。若本次突破受负雷劫抗性影响（如服用招雷散），战胜 MUST 额外获得本次突破扣除修为的 50% 作为补偿；补偿 MUST 经修为存储上限截断，实际发放为正时回复 MUST 展示「招雷淬体」及所获修为。

#### Scenario: 跨大境界突破成功

- **WHEN** 玩家战胜跨大境界雷劫
- **THEN** 等级提升、气血回满、四维提升 20% 并获得灵石奖励

#### Scenario: 渡劫期层级提升

- **WHEN** 玩家在渡劫期战胜当级雷劫
- **THEN** 等级提升、气血回满、四维提升 5%

#### Scenario: 招雷淬体补偿

- **WHEN** 玩家服用招雷散（负雷劫抗性）后渡劫战胜
- **THEN** 额外获得本次突破扣除修为的 50%（受存储上限截断），回复追加「招雷淬体：修为 +N」；无可发放时不展示该行
