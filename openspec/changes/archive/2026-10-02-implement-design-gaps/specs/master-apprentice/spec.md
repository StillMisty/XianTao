# Spec Delta

## Purpose

定义师徒与护道的行为契约：拜师/收徒的即时建立与全部门槛（境界差、一徒一师、收徒上限、脱离冷却）、师徒查看、逐出师门、叛师、自动出师、师徒修炼速度加成，以及护道关系的建立/解除/查询与突破成功率加成。详细公式、数据模型与实现细节见 `openspec/specs/master-apprentice/design.md`。

## ADDED Requirements

### Requirement: 师徒修炼加成

处于在师（ACTIVE）关系的徒弟 MUST 在历练修为结算中获得修炼速度乘数「1 + 师傅与自身等级差 × 0.002」，乘数上限 MUST 为 1.5；无师傅、关系非在师（已出师/已叛师/已逐出）或师傅缺失时 MUST 为基准 1.0。该乘数 MUST 与历练其它修为乘数连乘后统一取整，对中途结算与最终结算一并生效。

#### Scenario: 在师徒弟加成

- **WHEN** 处于在师关系且师傅等级高于自身的徒弟结算历练
- **THEN** 其修为乘数按 1 + 等级差 × 0.002 提高（最高 1.5），高于无师徒关系时

#### Scenario: 出师后无加成

- **WHEN** 已出师（关系非在师）的徒弟结算历练
- **THEN** 师徒乘数为 1.0，不再获得加成
