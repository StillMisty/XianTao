# Spec Delta

## Purpose

定义历练的行为契约：开始与结束条件、结算节奏（含中途自动结算与最短时长）、收益构成（玩家与出战灵兽的修为、物品）、等级衰减与效率影响、师徒与宗门练功房修炼乘数、动态遇怪与子事件、战斗中断与濒死、顿悟、高光战斗识别与结算输出。具体公式与实现细节见同目录 design.md。

## MODIFIED Requirements

### Requirement: 收益构成

历练结算 MUST 发放修为与物品两类收益，MUST NOT 发放灵石或铜币。玩家修为由基础修为与击杀修为组成，并 MUST 受修为存储上限截断。全部出战灵兽 MUST 同时获得独立历练修为：按本次未结算时长每分钟 2 点，与结算时段内战斗获胜所得一并发放；该修为 MUST 按未结算时段逐段累计，已结算时段 MUST NOT 重复发放。物品 MUST 来自当前地图的特产与怪物掉落配置，按权重随机选取并合并同名数量。

#### Scenario: 正常结算

- **WHEN** 玩家结算一段有战斗的历练
- **THEN** 修为增加、特产物品入包，结算回复展示修为与物品清单

#### Scenario: 修为存储上限

- **WHEN** 玩家修为已接近存储上限仍结算大量修为
- **THEN** 超出部分被截断，修为不超过上限

#### Scenario: 出战灵兽获得修为

- **WHEN** 玩家携带出战灵兽结算一段未结算历练
- **THEN** 全部出战灵兽按该段分钟数 × 2 获得修为，之后结算不再重复发放该段时长

### Requirement: 效率与修为基准

修为基准 MUST 同时受地图等级与玩家悟性影响（取较高者作为每分钟基准），身法 MUST 提高结算效率（有上限），机缘运势 MUST 修正修为收益。修为乘数 MUST 还包含师徒加成与宗门练功房加成：处于在师关系的徒弟 MUST 获得「1 + 师傅与自身等级差 × 0.002」的乘数（上限 1.5），练功房 MUST 按每级 +3% 提供乘数；全部乘数 MUST 连乘后统一取整，MUST NOT 逐项中间取整。结算回复 MUST 展示效率倍率。

#### Scenario: 身法提高效率

- **WHEN** 玩家身法较高
- **THEN** 结算效率倍率提高（不超过上限），回复展示「效率 N.Nx」

#### Scenario: 悟性与地图等级取高

- **WHEN** 玩家悟性换算的每分钟修为高于地图等级换算值
- **THEN** 基础修为按悟性换算值计算

#### Scenario: 师徒与练功房加成

- **WHEN** 处于在师关系且师傅等级高于自身的玩家，在所属宗门已建练功房时结算历练
- **THEN** 修为按效率、等级衰减、师徒乘数、练功房乘数与运势连乘后统一取整，高于无这两项加成时的结果
