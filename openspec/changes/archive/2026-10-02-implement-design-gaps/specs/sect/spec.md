# Spec Delta

## Purpose

定义宗门系统对玩家可观察的行为契约：宗门创建与总览、宗灵对话与权限分级、成员进出、贡献与商店、共享功法、建筑与升级。数值公式、数据模型与未实现设计见同目录 design.md。

## ADDED Requirements

### Requirement: 宗门动态事件

宗门 MUST 维护一条纯氛围的「最近大事」动态事件，该事件 MUST NOT 产生任何资源增减。事件 MUST 在查看宗门总览或与宗灵对话时惰性刷新：距上次生成超过 20~24 小时（按宗门 ID 确定性抖动）时 MUST 从模板池随机抽取一条新事件并尽量避开上一次的事件类型；首次访问且尚无事件时 MUST 立即生成。事件展示有效期 MUST 为 48 小时，超过有效期的事件 MUST 不再展示并视为已过期。并发刷新时 MUST 保证至多一条事件被写入，未写入的请求 MUST 展示当前有效事件。宗门总览 MUST 展示「最近大事」，宗灵对话上下文 MUST 包含该事件。

#### Scenario: 首次访问即生成

- **WHEN** 已入宗玩家首次查看宗门总览且该宗门尚无动态事件
- **THEN** 系统生成一条动态事件，总览的「最近大事」展示该事件文案

#### Scenario: 生成间隔内沿用

- **WHEN** 距上次事件生成不足该宗门的生成间隔（20~24 小时）
- **THEN** 不生成新事件，沿用现有事件

#### Scenario: 事件过期与无资源效果

- **WHEN** 上次事件已超过 48 小时有效期后玩家再次查看
- **THEN** 旧事件不再展示并在下次刷新时轮换为新事件，且任何动态事件都不改变宗门资金、成员贡献或玩家资源

## MODIFIED Requirements

### Requirement: 宗门建筑

宗主 MUST 可消耗宗门资金建造/升级建筑，每类建筑每宗 MUST 只有一座，升级费用 MUST 等于建造费用。建筑效果 MUST 对成员生效：藏经阁每级 +3 共享功法位；灵脉按 `小时 × 等级 × 100 / 24` 惰性结算注入宗门资金；药园按等级自动上架灵药（Lv.1 灵芝/茯苓 15 贡献、Lv.2 血参/金银花 40、Lv.3 雪莲/紫丹参 60，每级补 10 份）；练功房每级使成员历练结算的修为 +3%；炼丹房每级使成员炼丹评分 +5%；锻造坊每级使成员强化的灵石消耗 -5%（实际消耗 MUST NOT 低于 1）；护阵每级使成员作为防守方受到的伤害 -3%，减伤后伤害 MUST NOT 低于原伤害的 50%。无宗门或未建造时上述成员加成 MUST 按基准值（无加成）结算。建造或升级建筑后其加成 MUST 立即对成员生效。重复建造 MUST 被拒绝；达到最大等级 MUST 无法继续升级。

#### Scenario: 建造藏经阁

- **WHEN** 宗主建造藏经阁
- **THEN** 扣除 3000 资金，共享功法位上限提升 3

#### Scenario: 建造药园

- **WHEN** 宗主建造药园
- **THEN** 贡献商店自动上架灵芝与茯苓并补满库存

#### Scenario: 重复建造

- **WHEN** 对已建造的建筑再次执行建造
- **THEN** 建造被拒绝，资金不变

#### Scenario: 练功房加成历练修为

- **WHEN** 成员所属宗门建有练功房 Lv.2 并结算历练
- **THEN** 该次历练修为按 `等级 × 3%` 加成结算

#### Scenario: 炼丹、锻造与护阵加成

- **WHEN** 成员所属宗门建有炼丹房 Lv.1、锻造坊 Lv.1 与护阵 Lv.3
- **THEN** 炼丹评分按 +5%、强化灵石消耗按 -5% 结算，成员作为防守方受到的伤害按 -9% 结算
