# Spec Delta

## Purpose

定义地图与旅行的行为契约：地图信息查看、世界地图总览、节点类型与等级门槛、相邻关系与旅行耗时、旅行的开始与懒结算、旅途进度展示、到达事件，以及历练与秘境的入口约束。地图与事件的静态配置细节见同目录 design.md。

## ADDED Requirements

### Requirement: 世界地图总览

已绑定角色的玩家 MUST 能通过「地图列表」查看世界总览：逐张列出全部地图的名称、类型与推荐境界；配置了妖兽的地图 MUST 展示妖兽概览（名称列表），配置了相邻关系的地图 MUST 展示四方可达（相邻地图名称）。未配置妖兽或相邻关系的地图 MUST 省略对应段落且 MUST NOT 报错。总览 MUST 来自服务端当前配置；未绑定角色的玩家 MUST 收到「我要修仙」认证引导。

#### Scenario: 查看世界总览

- **WHEN** 已绑定玩家发送「地图列表」
- **THEN** 回复逐张展示地图名称、类型与推荐境界，并在配置存在时附妖兽概览与相邻可达

#### Scenario: 空配置地图

- **WHEN** 某地图未配置妖兽或相邻关系
- **THEN** 该地图条目仍正常展示名称、类型与境界，省略缺失段落且不报错

#### Scenario: 未绑定角色

- **WHEN** 未绑定角色的玩家发送「地图列表」
- **THEN** 收到「我要修仙」认证引导，不展示世界总览
