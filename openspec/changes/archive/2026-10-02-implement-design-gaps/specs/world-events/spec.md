# Spec Delta

## Purpose

定义世界事件系统的行为契约：事件列表查看与参与、参与门槛与错误反馈、自动生成与生命周期推进、事件链激活、环境事件在旅行/历练时的效果应用，以及经济与叙事事件对商铺的外部可观察影响。数据模型、效果格式与种子数值见同目录 design.md。

## ADDED Requirements

### Requirement: 区域事件生成与绑定

生成区域（REGIONAL）事件时，系统 MUST 按模板的 `valid_region_tags` 匹配地图节点并写入 `region_map_node_id`：标签为空时 MUST 从全部地图节点中随机绑定一个；标签非空时 MUST 只从区域标签与模板标签相交的地图节点中随机绑定；不存在匹配地图节点时该模板 MUST 跳过本轮生成。全局（GLOBAL）事件 MUST NOT 绑定地图节点。

#### Scenario: 绑定匹配区域

- **WHEN** 区域模板配置了 `valid_region_tags` 且存在标签匹配的地图节点
- **THEN** 生成的事件绑定到其中一个匹配的地图节点

#### Scenario: 无匹配地图跳过

- **WHEN** 区域模板的标签没有任何地图节点匹配
- **THEN** 该模板本轮不生成事件

#### Scenario: 无标签任选地图

- **WHEN** 区域模板未配置 `valid_region_tags` 且存在地图节点
- **THEN** 事件从全部地图节点中随机绑定一个

### Requirement: 叙事事件注入地灵对话

与地灵对话时，系统 MUST 将该玩家当前所在地可见的进行中叙事（NARRATIVE）类世界事件注入对话上下文（全局事件与绑定当前地图节点的区域事件合并），使地灵可在叙事中自然提及；经济、环境与参与类事件 MUST NOT 注入地灵对话。无可见叙事事件时 MUST 不附加事件上下文。

#### Scenario: 地灵知晓叙事事件

- **WHEN** 玩家与地灵对话且存在可见的进行中叙事事件
- **THEN** 对话上下文包含这些叙事事件的标题与描述，地灵可自然提及

#### Scenario: 当地叙事事件可见

- **WHEN** 绑定玩家当前地图节点的区域叙事事件正在进行
- **THEN** 该事件被注入本次地灵对话上下文

#### Scenario: 非叙事事件不注入

- **WHEN** 当前只存在经济或环境类世界事件
- **THEN** 地灵对话上下文不包含这些事件

## MODIFIED Requirements

### Requirement: 世界事件列表查看

「世界事件」MUST 展示玩家当前所在地可见的进行中事件：全局事件与绑定玩家当前地图节点的区域事件合并展示（全局在前、当地在后），绑定其他地图节点的区域事件 MUST NOT 出现在列表中。每条 MUST 包含类别名、编号、标题与描述；区域事件 MUST 标注「区域」；参与类且已开放参与的事件 MUST 展示参与人数（无限制时显示「参与人数：无限制」，有限制时显示已参与/上限）。没有进行中事件时 MUST 明确提示当前没有事件；列表末尾 MUST 引导使用「参与事件 <编号>」参与。

#### Scenario: 查看进行中事件

- **WHEN** 玩家发送「世界事件」且存在进行中事件
- **THEN** 回复列出当前所在地可见的全局事件与当地区域事件；区域事件带「区域」标记；参与类事件显示参与人数或「无限制」，并提示「参与事件 <编号>」

#### Scenario: 没有进行中事件

- **WHEN** 玩家发送「世界事件」且当前没有进行中事件
- **THEN** 回复「当前没有进行中的世界事件。」

#### Scenario: 异地区域事件不可见

- **WHEN** 存在绑定在其他地图节点的进行中区域事件
- **THEN** 该事件不出现在玩家当前所在地的事件列表中，玩家到达该地图后才可见
