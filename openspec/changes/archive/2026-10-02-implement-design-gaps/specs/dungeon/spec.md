# Spec Delta

## Purpose

定义秘境系统对玩家可观察的行为契约：秘境列表与准入条件、进入与实例互斥、进度查看、秘灵自然语言对话、区域探索与 POI 结算、区域推进与通关、通关奖励与每日上限、撤退，以及秘境之灵好感度与隐藏内容发现。秘境数据模型、工具集与数值细节见同目录 design.md。

## ADDED Requirements

### Requirement: 隐藏区域解锁

当秘境配置了隐藏区域时，系统 MUST 按该隐藏区域的 `trigger_after_resolve` 解锁：仅当其指定的全部 POI 均已探索（探索记录跨区域保留）时该隐藏区域才可进入；未满足时推进 MUST 跳过该隐藏区域，进入其后第一个可进入的区域。隐藏区域未配置触发条件时 MUST 不设门槛。

#### Scenario: 完成触发 POI 后进入隐藏区域

- **WHEN** 隐藏区域的 `trigger_after_resolve` POI 均已探索、当前区域主线已清且玩家要求推进
- **THEN** 推进进入该隐藏区域并返回其区域描述

#### Scenario: 未完成触发 POI 时跳过

- **WHEN** 隐藏区域的 `trigger_after_resolve` 尚有 POI 未探索且玩家要求推进
- **THEN** 跳过该隐藏区域，进入其后第一个可进入的区域；无更多可进入区域时按通关结算

#### Scenario: 未配置触发条件

- **WHEN** 隐藏区域未配置 `trigger_after_resolve`
- **THEN** 推进时可正常进入该隐藏区域

### Requirement: 秘境事件管道

秘境 MUST 通过异步事件管道产出探索内容：进入秘境与推进区域 MUST 各产出一条固定叙事；玩家每次成功探索一个 POI 后 MUST 按 20% 基础概率（受当日运势修正）掷骰触发一个秘境子事件，并 MUST 检查该秘境的隐藏事件（每人每个秘境至多触发一次）；发现隐藏地点 MUST 产出发现叙事；通关 MUST 产出结算叙事。上述事件 MUST 以未投递状态保存并随玩家下一次回复被动送出，MUST NOT 使用主动推送。

#### Scenario: 进入与推进叙事

- **WHEN** 玩家进入秘境或推进到下一区域
- **THEN** 产出对应固定叙事事件，并随玩家下一次回复投递

#### Scenario: 探索 POI 触发子事件

- **WHEN** 玩家探索一个 POI
- **THEN** 按概率触发秘境子事件或隐藏事件（也可能无事发生），事件随回复投递

#### Scenario: 通关结算叙事

- **WHEN** 玩家通关秘境
- **THEN** 产出通关结算叙事并随回复投递

## MODIFIED Requirements

### Requirement: 秘境准入条件

进入秘境前系统 MUST 校验模板配置的全部准入条件：位置条件（玩家必须在指定地图节点）、境界条件（等级范围）、宗门条件（玩家须为指定宗门的有效成员；未指定宗门时须为任意宗门成员）、道具条件（背包持有指定物品）、前置通关条件（已首通指定秘境）、隐藏完成条件（已完成指定隐藏事件）。任一条件不满足时 MUST 拒绝进入并以结构化原因说明；秘境列表 MUST 展示不可进入的秘境并标注对应原因。无配置条件时 MUST 不限制。

#### Scenario: 境界不足

- **WHEN** 玩家等级低于秘境最低境界要求并尝试进入
- **THEN** 拒绝进入并提示所需境界范围

#### Scenario: 不在入口位置

- **WHEN** 玩家不在秘境入口地图节点并尝试进入
- **THEN** 拒绝进入并提示当前不在秘境所在位置

#### Scenario: 无准入限制

- **WHEN** 秘境未配置任何准入条件
- **THEN** 玩家可直接进入

#### Scenario: 宗门不符

- **WHEN** 玩家未加入任何宗门（或不属于条件指定的宗门）并尝试进入带宗门条件的秘境
- **THEN** 拒绝进入并提示该秘境仅限指定宗门弟子进入

### Requirement: 秘境进度查看

玩家在秘境中发送「秘境」时，系统 MUST 展示静态进度概览：当前区域名、已探索地点数 / 主线地点总数、已用时长，且 MUST NOT 调用 LLM。进度分母 MUST 为当前区域非通道（PASSAGE）主线地点总数，分子 MUST 只统计当前区域已探索的主线地点；隐藏地点与通道 MUST NOT 计入分子或分母。不在秘境中时「秘境」MUST 回退为秘境列表。

#### Scenario: 查看进度

- **WHEN** 秘境中的玩家发送「秘境」
- **THEN** 回复「区域名 | 探索 x/y | 用时 Nmin」并引导继续用「秘灵 内容」探索

#### Scenario: 不在秘境中

- **WHEN** 不在秘境中的玩家发送「秘境」
- **THEN** 展示秘境列表而非进度

#### Scenario: 隐藏地点不计入进度

- **WHEN** 玩家探索了当前区域的隐藏地点
- **THEN** 探索进度的分子与分母都不包含隐藏地点
