# 命令参考手册

> 与实际命令面完全对齐。福地经营、秘境探索、商铺买卖、宗门事务均通过对应 NPC 的**自然语言对话**完成。

## 注册与角色

| 命令 | 说明 |
|------|------|
| `我要修仙 [道号]` | 注册新角色（附赠入门行囊） |
| `改号 [新道号]` | 更改道号（不可重名） |
| `状态` | 查看角色完整状态 |
| `今日运势` | 查看今日财运/机缘/气运 |

---

## 修炼与突破

| 命令 | 说明 |
|------|------|
| `突破` | 尝试突破；小境界为机缘判定，跨大境界/渡劫期需迎战雷劫 |
| `护道 [道号]` | 为对方护道（其突破时若同地图可获得加成） |
| `护道解除 [道号]` | 解除护道关系 |
| `护道查询` | 查询自己的护道关系 |

> 修为圆满冲击大境界前，「状态」中会出现「雷劫将至」情报，列明可能降临的天劫与备战手段。

## 福地与地灵

| 命令 | 说明 |
|------|------|
| `福地` | 查看福地总览状态 |
| `福地地块` | 查看地块布局详情 |
| `福地渡劫` | 迎接福地天劫考验 |
| `地灵 [内容]` | 与地灵自然语言交互 |

**地灵能做的事**（直接说人话即可）：

- 种植/收获：「在 1 号田种灵芝」「全部收获」
- 建造/升级/拆除：「在 2 号建个兽栏」「把 3 号升一级」
- 孵化/放生：「在 2 号栏孵个火羽鸡蛋」「放生 3 号」
- 灵兽管理：「让火羽鸡出战」「召回」「进化 1 号」「两只灵兽繁育」
- 送礼闲聊：「送你一株灵芝」「最近如何？」

## 秘境与秘灵

| 命令 | 说明 |
|------|------|
| `秘境` | 查看秘境列表 + 当前进度 |
| `秘境 [秘境名]` | 进入指定秘境 |
| `秘灵 [内容]` | 与秘境之灵对话，由它带路探索 |

**秘灵交互示例**：
- 「这里有什么？」→ 查看可探索的地点
- 「去探探那座古殿」→ 探索指定地点（战斗自动结算）
- 「继续深入」→ 区域探索完毕后推进下一区域
- 「撤退吧」→ 保留已获奖励离开

## 商铺与掌柜

| 命令 | 说明 |
|------|------|
| `掌柜 [内容]` | 与所在地图的掌柜自然语言交易 |
| `回收 [物品名]` | 快速出售物品给掌柜（无需对话） |

**掌柜示例**：
- 「有什么好货？」→ 看商品清单
- 「来两瓶聚气丹」→ 购买
- 「这柄剑你收不收？」→ 出售/议价

## 宗门与宗灵

| 命令 | 说明 |
|------|------|
| `宗门` | 查看宗门信息 |
| `宗门创建 [名称] [理念]` | 创建宗门 |
| `宗灵 [内容]` | 与宗灵对话办理宗门事务 |
| `宗门退出` | 退出宗门（贡献清零、遗忘共享功法、24 小时冷却） |
| `宗门解散` | 解散宗门（仅宗主） |

**弟子可托宗灵**：查商店/兑换商品、查功法库/学习共享功法、献上玉简换贡献、捐灵石换贡献、查建筑。
**长老/宗主可托宗灵**：邀请/逐出成员、任免职位、发布公告、审核上架功法；宗主还可升宗门等级、扩员、建造/升级建筑。
